# 한글 원고 가져오기

‘원고 가져오기’에서 `.hwp` 또는 `.hwpx`를 고릅니다. 원본 파일은 수정하지
않으며 제목 서식이나 회차 제목으로 나누거나 파일 하나를 회차 하나로 가져올 수 있습니다.

- HWP 5.x(한글 2002 이후)의 전체 BodyText 구역을 읽습니다. 미리보기 텍스트는 쓰지 않습니다.
- 본문, 제목 서식·개요, 굵게·기울임·밑줄·취소선·방점과 RGB 글자색을 읽습니다.
- 문단의 들여쓰기·내어쓰기·좌우 여백·정렬·쪽 나눔을 가져옵니다.
- 직접 입력한 앞쪽 공백·탭·줄바꿈·빈 문단도 보존합니다.
- 표·그림·도형·수식·각주 본문은 제외하며 빠진 수를 안내합니다. 머리말·꼬리말의 글은 본문에 섞지 않습니다.
- 암호 문서, 배포용 문서, HWP 3.x(한글 97)는 지원하지 않습니다. 한글에서 편집 가능한 HWP 5.x/HWPX 사본으로 저장해 주세요.

문단 길이는 원본의 글자 크기를 기준으로 앱의 정수 ‘자’ 단위로 환산합니다.
첫 줄은 ±10자, 좌우 여백은 각각 20자까지이며 소수 길이는 반올림합니다.
탭 문자는 보존하지만 한글의 개별 탭 위치, 글꼴별 폭, 글자별 크기·자간과
복잡한 쪽 배치는 재현하지 않습니다. HWP의 용지·머리말·꼬리말 설정은
가져오지 않으며 HWPX의 쪽 설정은 기존 선택 기능을 이용합니다.

내보내기는 HWPX와 DOCX를 사용합니다. HWP 내보내기는 제공하지 않습니다.
