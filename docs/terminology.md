# 화면 용어 원칙

앱 화면에 보이는 말은 작가가 평소에 쓰는 말로 쓴다. 이 문서는 개발 문서·코드에서 쓰는 용어와 화면에 쓰는 말을 짝지어 둔다. 개발 문서와 코드에서는 개발 용어를 그대로 써도 된다.

## 원칙

1. **개발 용어는 화면에 쓰지 않는다.** 스냅샷, 프리셋, 동기화 충돌, 형태소, 가상화 같은 말.
2. **한글(HWP) 사용자가 이미 아는 말은 그 뜻 그대로 쓴다.** 예: 한글에서 '주석'은 각주·미주를 뜻하므로, 원고에 붙이는 의견·댓글은 '메모'라고 부른다.
3. **문법 용어는 풀어서 먼저 말한다.** 필요하면 괄호로 용어를 덧붙인다. 예: "‘보여졌다’는 겹친 표현 (이중 피동)".
4. **버튼은 무슨 일이 일어나는지 동작으로 쓴다.** 예: "이 때로 되돌리기", "퇴고 전과 비교".
5. **상태 표시는 짧은 명사형으로 쓴다.** 예: "저장됨", "읽기 전용", "구상 중".
6. **숫자보다 문장.** 점수·등급·수치판 대신, 필요할 때만 한 줄 문장으로 알린다. 예: "대사가 평소보다 적음".

## 용어표

### 저장과 기록

| 개발 용어 | 화면에 쓰는 말 | 예 |
|---|---|---|
| 스냅샷 (목록) | 기록 | "이 회차 기록 3개" |
| 자동 스냅샷 | 자동 기록 | "자동 기록 · 14:20" |
| 수동 스냅샷 만들기 | 지금 원고 보관 | 버튼 "지금 원고 보관" |
| 스냅샷 복원 | 이 때로 되돌리기 | 되돌리기 전 지금 원고도 자동으로 기록됨 |
| 스냅샷 비교 | 지금과 비교 | |
| 퇴고 시작 스냅샷 | 퇴고 전 원고 | "퇴고 전과 비교", "퇴고 전 원고 보관됨" |
| 원자적 저장, 자동저장 | 저장됨 / 저장 중 | 상태 표시만 |
| 저장 실패 | 저장하지 못함 | "저장하지 못함 · 디스크 공간 부족" |
| 동기화 | 기기 간 맞추기 (설정 화면), 상태는 "다른 기기와 맞춤" | |
| 외부 변경 감지 / 동기화 충돌 | 다른 곳에서 바뀜 | "다른 기기에서 이 회차가 바뀜 · 둘 다 보기" |
| 휴지통 | 휴지통 | 그대로 |

### 원고 구조와 화면

| 개발 용어 | 화면에 쓰는 말 | 비고 |
|---|---|---|
| Document (회차·챕터) | 회차 / 챕터 | 프로젝트 유형에 따라 |
| Part | 부 / 권 | |
| 장면 구분자 | 장면 나눔 표시 | ◆, *** |
| 이어보기 | 이어보기 | 그대로 |
| 분할 창 | 나란히 보기 | |
| 읽기 전용 잠금 | 읽기 전용 / 잠금 해제 | |
| 접힘·펼침 | 접기 / 펼치기 | |
| 명령 팔레트 (Ctrl+K) | 빠른 이동 | |
| 가상화, 지연 로딩 | (화면에 쓰지 않음) | 필요하면 "불러오는 중" |
| 원고 서식 프리셋 | 서식 | "서식: 출판사 투고용" |
| 사용자 프리셋 | 내 서식 | |
| 원고지 매수 | 원고지 N매 | 그대로 |

### 메모와 설정

| 개발 용어 | 화면에 쓰는 말 | 비고 |
|---|---|---|
| 주석 (Note, anchor 있는 댓글) | 메모 | 본문 메모 / 회차 메모 / 작품 메모. 모아보기는 "메모함" |
| 답글 | 답글 | 그대로 |
| 해결 (resolve) | 완료 | 완료한 메모는 기본으로 숨김 |
| 태그 | 태그 | 그대로 |
| 설정 카드 | 설정 카드 | 그대로 |
| 별칭 | 다른 이름 | "다른 이름: 서하, 윤 사장" |
| 근거 있는 설정 (출처 연결) | 원고에서 확정된 설정 | 항목 옆에 출처 회차 |
| 복선 뿌림 / 회수 | 복선 뿌림 / 회수 | 웹소설 작가에게 익숙한 말. '떡밥'도 검색 별칭으로 인식 |

### 마감과 교정

| 개발 용어 | 화면에 쓰는 말 | 비고 |
|---|---|---|
| 넷째 작업 모드 (연재·출간 관리) | 마감 | 웹소설: 연재 일정, 출판: 교정 |
| 교정본 (편집자가 고친 파일) | 받은 교정본 | |
| 비교 기준 판본 | 편집자에게 보낸 원고 | "9월 20일 보냄" |
| diff 항목 | 바뀐 곳 | 지운 글자 취소선, 넣은 글자 밑줄 |
| accept / reject | 받아들이기 / 되돌리기 | "남은 곳 모두 받아들이기" |
| 미확인 변경 | 남은 곳 | |
| 편집자 코멘트 | 편집자 메모 | 한글 메모·Word 메모에서 가져옴 |
| 교정 단계 | 탈고 · 1교 · 2교 · 3교 · 인쇄 넘김 | 출판 현장 용어 그대로 |
| 판형 기준 쪽수 추정 | 예상 쪽수 | "신국판 예상 328쪽" |

### 퇴고 점검

| 개발 용어 | 화면에 쓰는 말 |
|---|---|
| 민감도 (느슨/보통/엄격) | 표시 (적게 / 보통 / 많이) |
| 규칙 | 점검 항목 |
| 요약 전용 (low severity) | 참고 |
| 작가 기준선 | 평소 ("평소보다 대사가 적음") |
| 회차별 추이 | 회차별 변화 |
| 형태소 분석 | (화면에 쓰지 않음) |

점검 항목 이름 (규칙 ID는 [revise-engine.md](revise-engine.md)):

| ID | 개발 이름 | 화면에 쓰는 말 (카드 제목 예) |
|---|---|---|
| A1 | 문장 시작 반복 | ‘그녀는’으로 시작하는 문장이 3번 |
| A2 | 종결 연속 | ‘-었다.’로 끝나는 문장이 4번 이어짐 |
| A3 | 가까이 반복 | ‘봉투’가 두 문장 안에 3번 |
| A4 | 습관어 | 자주 쓰는 말 · ‘문득’ 이 회차 6번 |
| A5 | 문형 반복 | 같은 모양의 문장이 이어짐 |
| B1 | 긴 문장 | 긴 문장 · 118자 |
| B2 | 리듬 단조 | 문장 길이가 너무 고름 |
| B3 | 문단 밀도 | 휴대폰에서 7줄이 넘는 문단 |
| C1 | 조사 '의' 과다 | 한 문장에 ‘의’가 5번 |
| C2 | 이중 피동 | ‘보여졌다’는 겹친 표현 → ‘보였다’ |
| C3 | 번역투 | 번역 투 표현 · ‘~에 대해’ |
| C4 | 대명사 과다 | ‘그녀’가 평소보다 많음 |
| C5 | 부사 밀도 | 꾸밈말이 평소보다 많음 |
| C6 | 시제 흔들림 | 과거와 현재가 섞임 |
| D1 | 화자 불분명 | 누가 말하는지 헷갈릴 수 있음 |
| D2 | 대사 태그 반복 | ‘말했다’가 한 장면에 5번 |
| D3 | 말투 일관성 | 서하는 존댓말 · ‘났어?’는 반말 |
| E1 | 이름 흔들림 | ‘서화’는 설정집에 없는 이름 |
| E2 | 호칭 흔들림 | 서하를 부르는 말이 바뀜 |
| E3 | 설정 모순 | 설정과 다름 · 눈 색 ‘회색’ (3화) |

## 적용 상태

- 디자인 캔버스 전체 보드: 적용함 (2026-09-27). 주석 → 메모, 스냅샷 → 기록, 해결 → 완료, 명령 창 → 빠른 이동, 동기화 완료 → 다른 기기와 맞춤, 장면 구분 → 장면 나눔 표시, EP. 12 → 12화.
- 설계 문서(screens, layout-data, mvp-scope, revise-engine): 기능 이름을 '메모'로 통일하고, 화면에 보이는 문구는 이 표 기준으로 바꿈. 개발 설명에는 개발 용어(스냅샷 등)를 그대로 쓴다.
