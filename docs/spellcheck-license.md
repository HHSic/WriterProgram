# 맞춤법 검사 엔진 라이선스 조사 (2026-09-26)

맞춤법 검사는 v0.2 대상. 설치형·로컬 우선 앱이므로 오프라인 동작 여부와 앱 번들 재배포 가능 여부가 핵심 기준.

## 세부 사항

### 바른한글 (나라인포테크)

- 부산대 인공지능연구실 권혁철 교수와 나라인포테크 공동 개발. 1990년대부터 무료 웹 서비스 제공.
- 웹 검사기 무료 사용은 개인 사용 범위. 앱에서 자동 호출하려면 API 계약 필요.
- 온라인 API와 오프라인 API 두 형태. 오프라인 API는 로컬 우선 구조와 잘 맞음.
- 확인할 것: 가격(기기당/사용자당/정액), Windows·macOS·Android·iOS 지원 여부, 앱 번들 재배포 조건, 1인 개발자·스타트업 요금.
- 문의: https://nara-speller.co.kr/order/

### hunspell-dict-ko

- 결과물 전체: GPL 3.0으로 배포.
- 사전 생성 코드와 일부 단어 데이터: MPL 1.1 / GPL 2.0+ / LGPL 2.1+ 삼중 라이선스.
- 대부분의 단어 데이터(국립국어원 사전 데이터 포함): CC BY-SA 4.0.
- hunspell 라이브러리: MPL/GPL/LGPL 삼중 라이선스. MPL 또는 LGPL 조건으로 사용 가능.
- 적용 시 주의:
  - 사전 파일을 앱과 별도 데이터 파일로 동봉하고 라이선스 고지·출처 표기.
  - 사전을 수정해 배포하면 수정본은 같은 라이선스로 공개.
  - 앱 코드와 결합 방식이 GPL 전파 대상인지 출시 전 법률 검토 권장.

## 권장안

1. **v0.2 기본 탑재**: hunspell-dict-ko (오프라인, 무료) + OS 내장 검사 병행 실험.
2. **고급 교정(유료 기능 후보)**: 바른한글 오프라인 API와 바른AI 견적을 받아 비교 후 선택.
3. **사용 금지**: 네이버·다음·부산대 웹 검사기 비공식 호출.
