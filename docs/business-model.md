# 운영 원칙과 비용 구조 (2026-09-27 결정, 2026-10-02 수정)

근거 조사는 [revenue-ai-report.md](revenue-ai-report.md).

## 결정

- **앱은 무료.** 집필, 구조, 설정집, 메모, 기록, 가져오기·내보내기, 교정본 비교, 기기 안에서 도는 퇴고 점검과 AI(의미 검색, 인물·용어 추출, 소리 내어 읽기), 외부 드라이브를 이용한 동기화, 자기 API 키 연결까지 모든 기본 기능은 무료다.
- **수입은 네 곳에서 온다.**
  1. **작가 플랜** (월 4,900원 / 연 49,000원): 우리 동기화 + 원고 공유·교정 협업 + 매달 AI 한도. 수입의 중심
  2. **AI 크레딧**: 한도를 넘겨 쓸 때. 원가를 공개하고 운영 수수료 10%를 별도 줄로 붙인다
  3. **후원**, 그리고 출시 전 크라우드펀딩
  4. **출판사·편집자 좌석** (교정 협업 기능 완성 후 시험)
- **유료는 실제로 서버·AI 비용이 드는 서비스만.** 쓰기·점검·내보내기 같은 핵심 기능은 절대 유료로 잠그지 않는다.
- **하지 않는 것**: 광고 네트워크, 원고 데이터 판매, 핵심 기능 유료 잠금.
- **유료 서비스와 AI를 쓰지 않으면 계정도 필요 없다.** 로컬 우선 원칙은 그대로 유지한다.

## 작가 플랜

| 항목 | 내용 |
|---|---|
| 가격 | 월 4,900원, 연 49,000원 (부가세 포함). 한컴독스 개인(월 6,900원)보다 낮게 |
| 우리 동기화 | 설정 없이 모든 기기, 종단간 암호화, 긴 버전 기록 (아래 "유료: 우리 동기화") |
| 원고 공유·교정 협업 | 베타리더·편집자에게 링크로 보내고 메모·교정을 받는다 (아래 "원고 공유") |
| 매달 AI 한도 | 100크레딧(원가 약 1,000원어치). 설정 모순 점검 약 15회, 또는 AI 독자 미리보기 약 14회 분량. 남은 한도는 다음 달로 넘기지 않는다 |
| 창작 과정 증명 | 증명서 만들기는 무료. 작가 플랜에는 검증 링크와 일지·시각 인증의 클라우드 보관 ([creation-proof.md](creation-proof.md)) |
| 해지 | 앱과 웹에서 버튼 하나로. 해지해도 원고와 기기 안 기능은 그대로, 동기화만 외부 드라이브 방식으로 돌아간다 |

- 실수령 추정: 4,900원에서 부가세와 결제 수수료(약 5%)를 빼면 약 4,230원. AI 한도 원가 약 1,000원을 빼고 약 3,200원이 서버·운영비 몫이다.
- 플랜 사용자가 우리 동기화 대신 외부 드라이브를 써도 혜택은 같다. **외부 드라이브를 쓴다고 AI를 더 주지는 않는다** (2026-10-02 검토): 우리 동기화의 작가당 비용은 월 수십~백몇십 원이라, 아낀 만큼 돌려주면 10~20크레딧에 그쳐 혜택이 되지 못하고, 크게 주면 AI 원가로 손해가 난다. 상품도 복잡해진다.

## 무료 사용자의 AI 체험

- 계정을 처음 만들 때 **한 번만 50크레딧**(약 500원어치)을 준다. 설정 모순 점검 몇 번, AI 독자 미리보기 몇 번을 해 볼 수 있는 양이다.
- 매달 주는 무료 한도는 두지 않는다. 사용자 1만 명이면 매달 수십만~수백만 원이 나가 작가 플랜 수입을 넘을 수 있다.
- 자기 API 키 연결(BYOK)과 기기 안 AI는 계속 무료다.
- 결제는 데스크톱·웹에서만 받는다 (아래 "충전"과 같은 이유).

## 동기화

### 무료: 외부 드라이브 이용 (우리 서버 없음)

| 기기 | 방식 |
|---|---|
| 데스크톱 | 원고 폴더를 iCloud Drive·Dropbox·OneDrive·Google Drive의 동기화 폴더에 둔다 |
| 애플 기기 (iOS·macOS) | iCloud Drive 폴더 |
| 모바일 전체 | 앱이 Google Drive·Dropbox·OneDrive에 직접 연결한다. 작가가 자기 계정으로 로그인하고, 인증 정보는 기기에만 저장하며, 파일은 우리 서버를 거치지 않는다 |

- iOS에서는 Dropbox·Google Drive의 폴더를 다른 앱이 계속 동기화하며 쓰기 어렵다 (옵시디언도 iOS는 iCloud와 자체 Sync만 공식 지원). 그래서 모바일은 드라이브 직접 연결로 해결한다.
- Google Drive는 앱이 만든 파일에만 접근하는 `drive.file` 권한을 쓴다. 구글이 민감하지 않은 권한으로 분류해 보안 심사 부담이 적다.
- 충돌 처리는 회차 단위 파일 기준으로 앱이 한다 (두 버전을 모두 보관하고 작가가 고름).

### 유료: 우리 동기화 (작가 플랜, v0.4 이후)

- 모든 기기에서 설정 없이 매끄럽게 동작한다.
- **종단간 암호화 필수.** 원고는 작가의 재산이라 운영자도 내용을 볼 수 없어야 한다.
- 서버에 긴 버전 기록을 보관한다.
- 원고는 텍스트라 용량이 작다 (한글 100만 자 ≈ 3MB). 저장 비용이 작아 낮은 가격으로 제공할 수 있다.
- 참고: 옵시디언 Sync는 월 $4(연간 결제, 1GB, 버전 기록 1개월) / 월 $8(10GB, 12개월).

## 원고 공유 (작가 플랜, v0.4 이후)

- 베타리더·편집자에게 회차나 원고 일부를 링크로 공유한다.
- 받은 사람은 브라우저에서 읽고 메모를 남긴다 (계정 없이도 가능하게).
- 남긴 메모는 작가 앱의 메모함으로 들어온다. 메모 기능과 상단 바의 권한·공유 자리([layout-data.md](layout-data.md))가 여기서 연결된다.
- 공유 범위, 기간, 메모 허용 여부를 작가가 정하고 언제든 링크를 끊을 수 있다.

## 후원

- 후원 창구 후보: GitHub Sponsors, Ko-fi, Buy Me a Coffee, 국내 후원 플랫폼. 한국 지원 여부와 수수료를 비교해 하나를 고른다.
- 후원자 혜택: 새 버전을 먼저 써보기 (옵시디언 Catalyst 방식). 기능을 잠그는 혜택은 두지 않는다.
- 앱 안의 후원 안내는 조용하게: 정보 화면, 업데이트 소식 정도. 작업 중에는 절대 띄우지 않는다.
- 모바일 앱 안의 후원 링크는 앱스토어 규정상 제한될 수 있다. 출시 전에 규정을 확인하고, 허용되지 않으면 모바일 앱에는 넣지 않는다.
- 운영비, 후원, 유료 서비스 수입을 정기적으로 공개하는 페이지를 둔다.

## AI 크레딧 운영 규칙

### 가격

- **1크레딧 = 10원** (원화 기준). 작가에게 토큰 같은 말은 보여주지 않는다.
- **크레딧 가격 = API 실비 + 운영 수수료 10% + 결제 수수료 + 부가세.** 영수증에 줄마다 따로 보인다.
- 운영 수수료는 AI 중계 서버, 결제·환불 처리, 단가 재계산 같은 운영에 쓴다. 숨기지 않는 것이 원칙이다 (2026-10-02, 마진 0에서 변경).
- 서버비는 작가 플랜 수입으로 충당하므로 크레딧에 따로 넣지 않는다. 예외는 아래 "서버비 비상 규칙".
- 작가 플랜의 매달 AI 한도에는 운영 수수료를 붙이지 않는다 (플랜 가격에 포함).
- 참고 추정 (5,000자 회차, 환율 1,400원): 회차 요약 약 1.5~13원, 설정 모순 점검 약 40~90원, AI 독자 5명 반응 약 10~70원. 한국어 토큰 수가 모델마다 크게 달라 시제품에서 실제 원고로 재서 확정한다.

### 차감과 표시

- 점검 전: 예상 크레딧 범위 ("예상 12~18크레딧").
- 점검 후: 실제 차감과 영수증 같은 내역 (API 원가, 운영 수수료, 결제 수수료, 부가세).
- 우리 쪽 오류(서버 장애 등)로 실패하면 차감하지 않는다.
- 결과가 "지적 없음"이어도 AI를 호출했으면 원가만큼 차감된다. 이 점을 점검 전에 안내한다.

### 충전

- 충전은 데스크톱에서 웹 결제로 한다. 모바일 앱 안에서 결제받으면 앱스토어 수수료(최대 30%)가 붙어 실비 원칙이 깨진다. 모바일은 충전된 크레딧을 쓰기만 한다 (앱스토어 결제·안내 규정은 출시 전 확인).
- 자기 API 키 연결 옵션도 둔다 (고급 설정). 이 경우 크레딧을 쓰지 않고 작가가 API 제공사에 직접 낸다.

### 단가 변경

- API 단가와 환율을 매월 1회 재계산한다.
- 크레딧 가격이 바뀌면 적용 7일 전에 공지하고, 이미 충전한 크레딧의 원화 가치는 바꾸지 않는다 (점검당 차감 크레딧 수가 바뀐다).
- 운영 수수료율을 바꿀 때는 30일 전에 공지한다.

### 서버비 비상 규칙

작가 플랜 수입, 운영 수수료, 후원으로 서버비를 감당하지 못할 때만 쓴다.

- **조건**: 월 서버비가 (작가 플랜 수입 + 운영 수수료 수입 + 후원)을 넘는 달이 2개월 이어질 때.
- **계산**: 점검 1회당 서버 몫 = 부족분 ÷ 지난달 AI 점검 수. 영수증에 "서버 몫" 줄로 따로 보인다.
- **상한**: 점검 1회당 최대 1크레딧(10원). 전기요금 연료비조정단가처럼 상한이 있어야 작가가 예측할 수 있다.
- **공지**: 적용 30일 전에 공지한다.
- **되돌림**: 다시 감당되면 0으로 되돌린다. 매 분기 재계산해 공개한다.

## AI 점검에서 원고 보호

- 기본은 꺼짐. 켤 때 "이 기능은 원고 일부를 AI 서버로 보냅니다"에 분명히 동의받는다.
- 보내는 범위는 해당 장면과 관련 설정 카드뿐. 무엇을 보냈는지 작가가 볼 수 있다.
- API 제공사의 데이터 보관 기간과 학습 사용 여부를 약관으로 확인해 안내문에 그대로 적는다. 가능하면 데이터를 보관하지 않는 설정(ZDR)으로 운영한다 (Anthropic의 최상위 Fable 계열은 30일 보관이 필수라 이 설정에서는 쓰지 않는다).
- "AI가 글을 써주는 기능이 아니라 읽고 점검하는 기능"으로 안내한다. 본문 생성·이어 쓰기는 넣지 않는다 (리디·카카오페이지가 AI 작품을 원칙적으로 금지하고, 작가 계약을 위험하게 만든다).

- 자기 API 키 연결(2026-10-03 구현)에서는: 키를 이 기기의 자격 증명 저장소에만 두고, 보낸 글과 답은 화면에만 있다가 사라진다. 켤 때 동의 문구에 "학습 안 함 계약이 있는 유료 키를 쓰라"와 "본문을 써 주는 기능은 없다"를 넣었다. 쓴 양은 토큰 수 문장으로만 보이고 값은 보이지 않는다(작가가 회사에 직접 냄).

### 원고가 학습에 쓰이지 않게

- **학습 안 함이 계약에 적힌 유료 API만 쓴다.** 무료 등급(예: Gemini API 무료 등급은 학습에 쓸 수 있음)은 쓰지 않는다. 약관을 분기마다 다시 확인하고, 바뀌면 작가에게 알린다.
- **기기 안에서 되는 일은 기기 안에서.** 의미 검색, 인물·용어 추출, 간단한 요약은 로컬 모델로 하고 원고를 내보내지 않는다.
- **보내는 양은 최소로.** 해당 장면과 관련 설정 카드만. 보내기 전에 보낼 내용을 보여 준다.
- **이름 가리기.** 인물·지명을 `인물A`, `장소B`처럼 바꿔 보내고 결과를 받은 뒤 되돌린다. 설정 모순 점검은 이름이 일관되기만 하면 된다.
- **우리 서버는 내용을 남기지 않는다.** 중계만 하고 원고 내용은 기록하지 않으며, 이 사실을 공개한다.
- **작가가 고른다.** AI는 기본 꺼짐. 자기 API 키로 직접 계약하거나, 로컬 모델만 쓰는 "오프라인 전용"을 고를 수 있다.

## 원고 데이터

- **원고를 데이터로 팔지 않는다.** "무료로 쓰는 대신 원고를 학습 데이터로" 같은 거래는 하지 않는다. 신뢰가 무너지고, 연재·출판 계약상 작가에게 팔 권리가 없는 경우가 많으며, 필수 동의로 묶으면 불공정 약관 문제가 생긴다.
- 장기 검토(사용자와 신뢰가 쌓인 뒤): 작가가 작품마다 직접 고르는 **AI 학습 라이선스 중개**. 기본 꺼짐, 수익 대부분(예: 70~80%)은 작가에게, 판매처·용도·금액 공개, 권리 확인과 익명화를 거친다.

## 광고

- 광고 네트워크(배너, 추적 광고)는 넣지 않는다. 집중을 방해하고, 광고 SDK의 추적이 로컬 우선·개인정보 원칙과 맞지 않으며, 데스크톱 앱의 광고 수입은 작다.
- 검토 후보: 추적 없는 **"작가 소식" 칸**. 공모전, 작법 강의, 플랫폼 모집 같은 작가에게 쓸모 있는 소식에 "후원 소식" 표시를 달아 싣는다. 시작 화면(작품 목록)에만 두고 쓰는 화면에는 절대 두지 않는다. 작가 플랜 사용자에게는 보이지 않는다. 사용자가 수천 명을 넘긴 뒤 시험한다.

## 참고한 사례

| 사례 | 가져온 것 |
|---|---|
| Obsidian | 앱 무료 + 사용자 후원(Catalyst) + 선택형 유료 서비스(Sync, Publish). VC 투자 없이 운영 |
| OpenRouter | AI 토큰 단가는 제공사 가격 그대로, 충전 시 수수료만 |
| 뮤블 | 무료 로컬 앱 + 후원 등급별 AI 한도. 가장 직접적인 국내 경쟁자 |
| 노벨라 | 텀블벅으로 출시 자금 6,019만 원 (후원자 845명) |
| Buffer, Signal | 운영비가 어디에 쓰이는지 항목별 공개 |
| 항공 유류할증료, 전기요금 연료비조정단가 | 비용 변동분을 별도 줄로 두고 공식대로 올리고 내림, 기준 아래면 0, 상한 |

## 출시 전 확인할 것 (법·플랫폼)

- 선불 충전금 관련 규정(전자금융거래법 등)과 환불 의무(전자상거래법).
- 크레딧·유료 서비스 판매와 후원 수입에 따른 사업자 등록, 부가세 신고.
- 앱스토어의 결제·외부 결제 안내·후원 링크 규정 (한국의 대체 결제 허용 범위 포함).
- 후원 플랫폼의 한국 지원 여부와 수수료.
- Google Drive·Dropbox·OneDrive API의 앱 등록·심사 절차와 사용량 한도.
