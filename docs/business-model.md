# 운영 원칙과 비용 구조 (2026-09-27 결정)

## 결정

- **앱은 무료, 운영은 후원으로.** 집필, 구조, 설정집, 메모, 기록, 가져오기·내보내기, 기기 안에서 도는 퇴고 점검까지 모든 기본 기능은 무료다.
- **AI 점검만 선택형 크레딧.** 크레딧은 원가를 공개하고 마진을 붙이지 않는다.
- **AI를 쓰지 않으면 계정도 필요 없다.** 로컬 우선 원칙은 그대로 유지한다.

## 비용이 드는 곳

| 항목 | 언제 생기나 | 규모 | 충당 |

| 서버 | AI 크레딧 도입 시 (중계 서버, 계정, 크레딧 장부, 결제 연동) | 초기에는 서버리스 무료 등급 안 ~ 월 몇만 원 | 후원 (나중에 크레딧, 아래 규칙) |
| Windows 코드 서명 | 배포 시작 시 | 연 수만~수십만 원 (방식에 따라) | 후원 |
| Apple 개발자 계정 | iOS·macOS 배포 시 | 연 $99 | 후원 |
| 도메인·홈페이지 | 배포 시작 시 | 정적 호스팅이면 거의 없음 | 후원 |
| 앱 업데이트 배포 | 배포 시작 시 | GitHub Releases (저장소 공개 시 무료) | - |

v0.1~v0.3은 서버가 없다. 서버는 AI 크레딧(v0.4)부터 생긴다.

## 후원

- 후원 창구 후보: GitHub Sponsors, Ko-fi, Buy Me a Coffee, 국내 후원 플랫폼. 한국 지원 여부와 수수료를 비교해 하나를 고른다.
- 앱 안의 후원 안내는 조용하게: 정보 화면, 업데이트 소식 정도. 작업 중에는 절대 띄우지 않는다.
- 모바일 앱 안의 후원 링크는 앱스토어 규정상 제한될 수 있다. 출시 전에 규정을 확인하고, 허용되지 않으면 모바일 앱에는 넣지 않는다.
- 운영비와 후원 금액을 정기적으로 공개하는 페이지를 둔다.

## AI 크레딧 운영 규칙

### 가격

- **1크레딧 = 10원** (원화 기준). 작가에게 토큰 같은 말은 보여주지 않는다.
- **크레딧 원가 = API 실비 + 결제 수수료 + 부가세.** 마진 0.
- 서버 몫은 처음에는 넣지 않는다 (후원으로 충당). 넣게 되는 조건은 아래 "서버비 반영 규칙".
- 참고 추정: Claude Opus 5로 5,000자 회차 한 번 점검 ≈ $0.10 → 환율 1달러 1,400원, 수수료·세금 포함 약 150~170원 (15~17크레딧). 한국어 원고의 실제 토큰 수는 시제품에서 측정해 확정한다.

### 차감과 표시

- 점검 전: 예상 크레딧 범위 ("예상 12~18크레딧").
- 점검 후: 실제 차감과 영수증 같은 내역 (API 원가, 결제 수수료, 부가세, 서버 몫).
- 우리 쪽 오류(서버 장애 등)로 실패하면 차감하지 않는다.
- 결과가 "지적 없음"이어도 AI를 호출했으면 원가만큼 차감된다. 이 점을 점검 전에 안내한다.

### 충전

- 충전은 데스크톱에서 웹 결제로 한다. 모바일 앱 안에서 결제받으면 앱스토어 수수료(최대 30%)가 붙어 실비 원칙이 깨진다. 모바일은 충전된 크레딧을 쓰기만 한다 (앱스토어 결제·안내 규정은 출시 전 확인).
- 자기 API 키 연결 옵션도 둔다 (고급 설정). 이 경우 크레딧을 쓰지 않고 작가가 API 제공사에 직접 낸다.

### 단가 변경

- API 단가와 환율을 매월 1회 재계산한다.
- 크레딧 가격이 바뀌면 적용 7일 전에 공지하고, 이미 충전한 크레딧의 원화 가치는 바꾸지 않는다 (점검당 차감 크레딧 수가 바뀐다).

### 서버비 반영 규칙

사용자가 늘어 후원으로 서버비를 감당하지 못하게 되면 서버비를 크레딧에 포함한다.

- **조건**: 월 서버비가 월 후원액을 넘는 달이 2개월 이어질 때.
- **계산**: 점검 1회당 서버 몫 = 지난달 서버비 ÷ 지난달 AI 점검 수. 영수증에 "서버 몫" 줄로 따로 보인다.
- **공지**: 적용 30일 전에 공지한다.
- **되돌림**: 후원으로 다시 충당되면 서버 몫을 0으로 되돌린다.
- 매 분기 재계산해 공개한다.

## AI 점검에서 원고 보호

- 기본은 꺼짐. 켤 때 "이 기능은 원고 일부를 AI 서버로 보냅니다"에 분명히 동의받는다.
- 보내는 범위는 해당 장면과 관련 설정 카드뿐. 무엇을 보냈는지 작가가 볼 수 있다.
- API 제공사의 데이터 보관 기간과 학습 사용 여부를 약관으로 확인해 안내문에 그대로 적는다. 가능하면 데이터를 보관하지 않는 설정(ZDR)으로 운영한다 (Anthropic의 최상위 Fable 계열은 30일 보관이 필수라 이 설정에서는 쓰지 않는다).
- "AI가 글을 써주는 기능이 아니라 점검만 하는 기능"으로 안내한다.

## 출시 전 확인할 것 (법·플랫폼)

- 선불 충전금 관련 규정(전자금융거래법 등)과 환불 의무(전자상거래법).
- 크레딧 판매와 후원 수입에 따른 사업자 등록, 부가세 신고.
- 앱스토어의 결제·외부 결제 안내·후원 링크 규정 (한국의 대체 결제 허용 범위 포함).
- 후원 플랫폼의 한국 지원 여부와 수수료.
