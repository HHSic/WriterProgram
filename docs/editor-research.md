# 편집자 업무 조사와 편집자 공간 수익 모델 (2026-10-02)

작가는 무료로 두고 작가와 일하는 회사(웹소설 CP, 단행본 출판사)가 좌석 비용을 내는 "편집자 공간"이 될 수 있는지 보기 위해, 편집자가 지금 어떻게 일하는지 공개 자료로 조사했다. 익명 게시글·홍보성 블로그가 섞여 있어 아래 사실은 "현장 확인이 필요한 가설"로 다룬다. 수익 모델 전체는 [revenue-ai-report.md](revenue-ai-report.md), [business-model.md](business-model.md).

## 1. 웹소설 CP 편집자(PD)

### 하는 일과 도구

- 한 명이 연재 중·준비 중 작품을 5~6개, 많으면 9~10개 맡는다. 매니저 한 명이 작가 수십 명을 관리한다는 말도 있다 (DC 웹소설연재갤 2023-02, 루리웹 2023-04, 익명).
- 업무: 작가 영입·관리, 원고 받기, 교정·교열, 연재 일정, 이북 발간, 플랫폼 업로드, 표지, 마케팅, 정산 (원티드 공고, tanma.kr).
- 연재작은 "원고 전달 → 교정 → 제작 → 공개가 몇 시간 안에" 돈다. 교정교열을 매일 또는 주 단위로 완결까지 반복한다 (브런치 @editory 2022, @qsza45 2019).
- 도구는 엑셀·워드·한글 정도면 된다는 9년 차 편집자의 답이 있다 (잡코리아 2024-11). CP·편집자 전용 원고 관리 도구는 찾지 못했다.

### 원고와 교정이 오가는 방식

- **한글(hwp)이 사실상 표준.** "교정을 주고받다 보면 어떤 걸 쓰든 돌고 돌아 hwp로 돌아온다" (Threads, 2025).
- **교정 표시는 색 글자와 직접 수정이 주류.** 외주 교정 상품이 "띄어쓰기는 따로 표기하지 않고, 그 외 수정은 색상 표시"하고, 요청하면 "교정 부호가 없는 최종 수정본"을 따로 준다 (크몽 교정 상품). 한글 변경 내용 추적은 2014판부터 있지만 얼마나 쓰는지는 확인하지 못했다.
- 외주 교정 가격: 공백 포함 1자당 1원, 5천 자당 7,500~25,000원, 1~3일 (크몽).
- 회차 분량: 카카오페이지 약 5,500자, 문피아 유료 5,000자 권장.

### 보고된 문제

| 문제 | 근거 |
|---|---|
| 원고 분실, 담당자 교체 때 인수인계 실패 | 편집자가 세 번 바뀌고 인수인계 미비로 원고가 분실된 사건이 소송까지 갔다 (로톡뉴스 2026-09-21) |
| 피드백 지연 | 1~5화를 보내면 빨라야 7~10일 (DC 2023-01, 익명) |
| 교정 품질 저하 | "PD의 교정 교열 능력이 전반적으로 떨어진다" (예스24 채널 2025-03) |
| 교정 반영 때 서식 깨짐 | "교정보다 서식 복구에 시간이 더 든다" (경쟁 업체 블로그 2026-07, 홍보성) |
| 편집자 과로 | 밤에 원고 처리, 몇 년 안에 번아웃 (DC 2023-02, 익명) |

### 시장 규모

- 2022 실태조사(CP 113곳 응답): 평균 종사자 9.5명, 웹소설 인력 7.1명, 소속 작가 평균 16.4명, 평균 매출 9.9억 원.
- 2024 실태조사(CP 152곳): 응답 기업 평균 매출 164.5억 원. 대형사·플랫폼이 포함된 영향으로 보이며 중앙값은 확인하지 못했다.
- 전체 CP는 약 2천 곳이고 1인·2~3인 CP가 많다는 비공식 목록이 있다(날짜 없음). 카카오엔터는 자회사 CP를 통합 중이다(2026-08).

### 비슷한 도구

- 국내: CP·편집자 전용 원고·교정 관리 도구는 찾지 못했다. 가까운 것은 HWPX 서식을 유지하며 AI로 교정하는 AI Publishing Agent(월 4,900~29,900원), 작가용 서사공방·타입탁·펜시브·노벨라.
- 해외: Consonance(출판사 타이틀·일정 관리) 사용자당 월 $99, Pressbooks 기관 연 $5,999부터.

## 2. 단행본 출판사 편집자

### 흐름

| 단계 | 파일 | 우리 앱과의 관계 |
|---|---|---|
| 원고 접수, PC교(조판 전 교정 1~2회) | 한글(hwp)이 주류, 일부 워드 | **교정본 주고받기가 맞는 곳** |
| 조판 | 인디자인 (편집 디자이너) | 스타일이 정리된 원고를 넘겨 서식 정리 시간을 줄일 수 있다 |
| 저자교, 초교·재교·삼교·OK교 | 인디자인이 만든 PDF, 출력한 종이 교정지(빨간 펜), 아이패드 주석 | 지금은 대상 밖. PDF 교정은 나중 확장 후보 |
| 인쇄 | - | - |

- 문학동네 원고 모집은 "HWP 혹은 PDF"만 받는다. 맥용 한글에는 변경 내용 추적이 없다는 사용자 글이 있다.
- 편집자는 한 권을 3~6번 정독하고 편집·교정에 약 3개월이 걸린다 (문학동네 편집자 인터뷰, 2022).

### 보고된 문제

- 조판 뒤 저자가 크게 고치면 디자이너 작업이 다시 생긴다. 출판 표준계약서 제11조에 수정으로 늘어난 제작비를 저자와 나누는 조항이 있을 정도다.
- 편집자가 넘긴 수정을 디자이너가 빠뜨려 일정이 늦어진다.
- 버전 혼선, 교정지 왕복 시간을 숫자로 다룬 자료는 찾지 못했다.

### 시장 규모

- 등록 출판사 81,161곳 중 2024년에 실제로 책을 낸 곳은 5,911곳. 소설 신간 3,289종.
- 출판 사업체의 62.4%가 매출 1억 원 미만, 약 90%가 10억 원 미만.
- 교정은 외주가 많다. 20년 경력 외주 편집자의 교정 단가가 장당 500~600원으로 25년째 거의 그대로다(2023 설문).

### 비슷한 도구

- 한컴독스 기업 1인당 월 8,250원(연간) / 10,900원(월간).
- 해외 교정 확인 도구는 사용자 무제한 팀 정액이 많다: Markup.io 월 $79, Filestage 월 €199~329. Adobe InCopy 월 $4.99.

## 3. 판단

1. **첫 고객은 웹소설 CP다.** CP의 일은 처음부터 끝까지 한글 원고를 주고받는 단계라 교정본 주고받기와 겹치는 부분이 크고, 매일·매주 반복되어 쓸 일이 많다. 전용 도구가 없는 빈 곳이다. 단행본 출판사는 조판 전 단계만 겹쳐서 두 번째로 둔다. PDF 교정지까지 다루면 그때 다시 본다.
2. **보고된 문제가 기능과 바로 맞는다.**

| 현장 문제 | 편집자 공간 기능 |
|---|---|
| 원고 분실, 담당자 교체 때 인수인계 실패 | 작품별로 받은 원고·교정 이력이 회사 공간에 남는다. 담당자가 바뀌어도 그대로 |
| 피드백 지연, 마감 관리 | 담당 작품의 회차 제출·교정 진행·연재 일정 현황판 |
| 색 글자 교정을 원본에 옮기다 서식이 깨짐 | 교정본을 앱이 비교하고 작가가 받아들이기만 하면 반영된다. "교정 표시 없는 최종본"도 바로 나온다 |
| 교정 품질 편차 | 회차별로 바뀐 곳 목록이 남아 검토하기 쉽다 (작가 쪽에서도 확인) |
| 외주 교정자와 주고받기 | 외주 교정자를 공간에 초대(교정자 좌석 또는 무료 손님) |

3. **가격은 좌석당이 아니라 팀 정액이 맞다.** CP 대부분이 작다(웹소설 인력 평균 7명, 1~3인 CP 다수). 해외 교정 도구도 팀 정액으로 간다.

| 등급 | 대상 | 가격 (가정) |
|---|---|---|
| 1인 | 1인 CP, 외주 교정자 | 월 9,900원 |
| 팀 | 편집자 5명까지 | 월 39,000원 |
| 회사 | 편집자 20명까지, 여러 레이블 | 월 99,000원 |
| 대형 | 플랫폼 자회사, 대형 출판사 | 견적 |

참고 기준: 한컴독스 기업 1인당 월 8,250~10,900원, Consonance 사용자당 월 $99. 작가는 계속 무료이고, 편집자가 초대한 작가는 회사 공간과 주고받는 기능을 무료로 쓴다.

4. **규모 가정**: 팀 등급 이상을 쓸 만한 CP가 수백 곳 이하라고 보면, 예를 들어 100곳 × 월 평균 5만 원 = 월 500만 원. 1인 등급 외주 교정자·1인 CP 300명 × 9,900원 = 월 약 300만 원(부가세·수수료 전). 숫자는 모두 가정이다.

5. **전제**: 교정본 주고받기(작가 쪽)가 먼저 완성되어야 한다. 편집자 공간은 서버가 필요하다(작가 플랜 서버와 같이).

## 4. CP가 지금 돈을 내는 곳 (2026-10-02 검토)

지금 CP가 **원고 주고받기 자체에 돈을 내는 곳은 없다.** 한글 파일을 메일·메신저로 주고받는 것은 공짜다. 편집자 공간이 팔릴지는 가설이고, 이 모델의 가장 큰 위험이다.

| 지출 | 내용 | 우리와의 관계 |
|---|---|---|
| 한글 라이선스 | 회사에서 쓰려면 기업용을 산다 (한컴독스 기업 1인당 월 8,250~10,900원) | "한글 원고에 돈을 낸다"는 감각은 이미 있다 |
| 외주 교정 | 공백 포함 1자당 약 1원. 회차(5,000자)당 약 5,000원, 100화면 약 50만 원 | 실제로 나가는 현금. 외주 교정자와 주고받기를 쉽게 하면 여기에 붙을 수 있다 |
| 편집자 인건비 | 서식 복구, 교정 반영 확인, 원고 찾기, 마감 독촉 | 보이지 않는 비용. 우리가 줄이는 것은 주로 이것 |
| 사고 비용 | 원고 분실, 인수인계 실패, 마감 펑크 | 드물지만 소송까지 간다 |

- 파는 논리는 "새 지출"이 아니라 "숨은 비용 줄이기"다. PD 한 명이 하루 30분을 덜 쓰면 인건비로 월 십수만 원어치 시간이다(PD 월급 250~300만 원 가정). 계산상으로는 팀 등급(월 39,000원)보다 크다.
- 하지만 작은 CP일수록 "지금도 공짜로 된다"고 느끼고, 인건비 절감은 체감이 약하다. 영세 시장에서 B2B 도구가 자주 실패하는 이유다.
- 비슷한 수요에 돈을 받는 국내 사례: HWPX 서식을 유지하며 AI로 교정하는 서비스(월 4,900~29,900원). 실제 판매량은 모른다.

**접근 방식**

1. **처음에는 CP에 무료로 준다.** CP가 소속 작가에게 앱을 쓰게 하면 작가 사용자를 얻는다. 돈보다 사용자 확보 경로로 먼저 쓴다.
2. **돈은 가치가 분명한 회사 기능에서 받는다**: 여러 편집자가 함께 쓰는 회사 공간, 작품 이력 보관, 담당자 교체 때 인수인계(서버가 들고 회사 단위 가치가 분명하다), 외주 교정자 연결·관리(이미 현금이 오가는 곳).
3. **수익 계획은 작가 플랜 → 편집자 공간 순서로 두되, 인터뷰 전에는 편집자 공간 수입에 크게 기대지 않는다.** 위 3장의 등급·규모 숫자는 인터뷰로 확인하기 전까지 가정이다.

인터뷰에서 꼭 물을 것: 원고·교정 때문에 가장 시간을 많이 쓰는 일, 그것이 줄면 회사가 낼지 개인이 낼지, 지금 쓰는 유료 도구.

## 5. 확인할 것 (현장)

- 웹소설 PD 3~5명 인터뷰: 하루 흐름, 원고 받는 경로(메일·카톡·드라이브), 교정 표시 방식(색 글자·변경 추적 비율), 담당자 교체 때 무엇을 넘기는지, 돈을 낼 사람(편집자 개인인지 회사인지).
- 외주 교정자 2~3명: 교정 파일 형식과 표시 규칙, 쓰는 도구, 불편한 점.
- 단행본 편집자 1~2명: 조판 전 교정의 비중, 저자교를 받는 방식.
- 시범 운영: CP 2~3곳에 무료로 써 보게 하고 계속 쓰는지 본다.
