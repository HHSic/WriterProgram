## 프로젝트 유형

원칙: **공통 핵심 + 유형별 확장.** 쓰는 과정(구조, 쓰기, 고치기, 구상, 설정집, 메모)은 같고, 원고를 넘기는 마지막 단계("마감" 모드)만 다르다.

| | 공통 | 웹소설 | 출판 장편 |
|---|---|---|---|
| 기본 단위 | 부 > 회차/장 | 회차 | 장 |
| 상태 | 초안 · 퇴고 · 완료 | + 비축 · 예약 · 연재됨 | + 탈고 · 1교 · 2교 · 3교 |
| 분량 | 글자 수(공백 포함/제외) | 회차 목표 (예: 공백 포함 5,000자) | 원고지 매수, 판형 기준 예상 쪽수 |
| 주 출력 | 서식에 맞춘 내보내기 | 플랫폼 붙여넣기용 txt/클립보드 | HWPX/docx 원고 |
| "마감" 모드 | 마감 달력 | 연재 일정, 비축, 끊기 후보, 휴대폰 미리보기 | 교정본 주고받기, 교정 단계, 판형 미리보기 |
| 퇴고 기준 | 공통 규칙 | 휴대폰 화면의 빽빽한 문단, 긴 문장 70자 | 한 문장 문단 연속, 긴 문장 90자 |

유형은 용어·상태·기본 서식·기본 목표·"마감" 모드 내용·퇴고 기준만 바꾸고 내부 데이터 구조는 같다.

### 교정본 주고받기 (출판 기성 작가 기준, 웹소설 계약 작가도 사용)

1. **보내기**: 장·회차를 골라 HWPX/docx로 내보낸다. 앱이 "편집자에게 보낸 원고"를 기록으로 남긴다.
2. **받기**: 편집자가 한글·Word에서 고친 파일을 가져온다. 보낸 원고와 비교해 바뀐 곳을 보여주고, 편집자가 단 메모(한글 메모·Word 메모)는 앱 메모로 들어온다.
3. **반영**: 바뀐 곳마다 받아들이기/되돌리기, 남은 곳 모두 받아들이기. 교정 단계(탈고 → 1교 → 2교 → 3교 → 인쇄 넘김)와 회신 마감일을 표시한다.

### 나중에 붙일 작은 기능

- **공모전 제출 점검**: 분량 제한(원고지 매수), 파일 형식, 원고에 작가 이름이 남아 있지 않은지.
- **투고 기록**: 어느 출판사에 언제 보냈는지, 답장.

## 구조 모델: 트리 + 자동 개요

- **트리 = 저장 단위.** 작품 > 부/권(폴더) > 회차·챕터(문서 파일). 동기화·스냅샷·분량 목표·내보내기 모두 문서 단위.
- **문서 내부 = 자동 개요.** 제목 서식과 장면 구분자(`***`, `◆` 등, 설정 가능)를 자동 탐지해 사이드바 개요로 표시. 클릭 시 해당 위치로 이동.
- **장면은 파일이 아니다.** 장면은 문서 안의 구분자로만 표현한다. 파일 수와 구조 복잡도를 줄이기 위함.
- **이어보기 모드.** 트리에서 여러 문서를 선택하면 하나의 연속 문서처럼 읽고 편집. 저장은 각 문서 파일로 분리.
- **분할/병합.** 커서 위치에서 새 회차·챕터로 분할, 인접 문서 병합.

## 서식 모델: 작성 화면과 원고 서식 분리

작성 화면에서 보는 모양과 출력되는 원고 모양을 분리한다 (Scrivener의 compile 개념, 단 훨씬 단순하게).

### 작성 화면 설정 (개인·기기별, 파일에 저장되지 않음)

글꼴, 글자 크기, 줄 간격, 자간, 문단 간격, 첫 줄 들여쓰기, 본문 폭, 테마(라이트/다크). 원고 파일에는 영향 없음.

### 원고 서식 (프로젝트 설정, 내보내기에 적용)

| 항목 | 단위 / 선택지 |
|---|---|
| 용지 | A4, B5, A5, 신국판(152×225mm), 46판(128×188mm), 사용자 지정 |
| 여백 | mm (위·아래·안쪽·바깥쪽) |
| 글꼴 / 크기 | pt |
| 줄 간격 | % (한글과 같은 방식, 기본 160%) |
| 자간 | % (한글과 같은 방식, 기본 0%) |
| 첫 줄 들여쓰기 | 글자 수 단위 (기본 1자) |
| 문단 구분 | 들여쓰기 / 빈 줄 / 둘 다 |
| 장 시작 | 새 쪽에서 시작 여부 |
| 머리말·꼬리말·쪽 번호 | 켜기/끄기, 위치, 꼬리말 직접 쓰기 |

단위는 한글(HWP) 사용자에게 익숙한 방식(pt, %)을 따른다. HWPX 내보내기 시 문단 모양·글자 모양으로 그대로 옮긴다.

### 기본 프리셋

- **출판사 투고 (A4)**: A4, 바탕체 계열 10pt, 줄 간격 160%, 첫 줄 들여쓰기 1자, 문단 사이 빈 줄 없음.
- **웹소설 플랫폼**: 용지 없음(연속), 들여쓰기 없음, 문단 사이 빈 줄 1줄.
- **사용자 프리셋**: 위 항목을 조정해 저장. 프로젝트 간 공유 가능.

프로젝트 유형이 기본 프리셋을 정한다(웹소설 → 웹소설 플랫폼, 출판 장편 → 출판사 투고).

### 문단과 줄 나누기

- Enter = 새 문단, Shift+Enter = 문단 안 줄 나누기. 모바일은 편집 도구줄에 줄 나누기 버튼.
- 문단 간격을 화면에 표시해 빈 줄용 Enter 두 번이 필요 없게 한다. 의도적인 빈 문단은 허용.
- 가져오기 시 줄바꿈 해석(줄바꿈 하나 = 문단 / 빈 줄 = 문단 구분)을 미리보기에서 선택.

## 긴 원고 탐색과 로딩

작가는 앞 회차를 자주 빠르게 되짚어 본다. 원고가 길어도 탐색이 멈추거나 막히면 안 된다.

- **지연 로딩 + 가상화**: 이어보기·긴 문서에서 화면 근처 문서만 에디터로 렌더링. 나머지는 가벼운 자리표시로 유지.
- **높이 추정**: 자리표시 높이를 글자 수로 추정해 스크롤바 위치·길이가 실제와 크게 어긋나지 않게 한다. 로딩 후 위치가 튀지 않도록 스크롤 앵커 유지.
- **막지 않는 로딩 표시**: 로딩 중인 구간은 회차 제목 + 스켈레톤 줄 + "불러오는 중"으로 표시. 스크롤·입력은 계속 가능. 150ms 안에 끝나면 표시하지 않아 깜빡임 방지.
- **빠른 이동 스크롤바**: 스크롤바 옆에 회차 눈금 표시. 스크롤바를 끌면 현재 위치의 회차 번호·제목 말풍선 표시.
- **미리 불러오기**: 현재 위치 앞뒤 문서를 미리 로딩. 최근 본 문서는 메모리 캐시.
- **분할 창**: 앞 회차를 분할 창(읽기 전용 잠금 가능)으로 띄워 현재 회차를 쓰면서 참고. 모바일은 하단 시트.
- **목표 성능**: 로컬 문서 열기 100ms 이내, 스크롤 60fps. 회차 300개·100만 자 프로젝트로 측정.

## v0.1 기능

화면·영역 설계는 [screens.md](screens.md), [layout-data.md](layout-data.md). 화면 문구는 [terminology.md](terminology.md).

1. **프로젝트 구조**: 위 구조 모델. 트리 드래그로 순서 변경, 이어보기, 분할/병합. 회차 시놉시스, 상태 라벨(초안/퇴고/완료, 웹소설은 비축/예약/연재됨 + 비축 N화 표시), 개요 표.
2. **에디터**: 한글 IME 안정성 최우선. 기본 서식, 집중 모드, 다크 모드, 작품 전체 찾기/바꾸기. 가운데 탭, 2분할(읽기 전용 잠금). 따옴표·말줄임표 자동 변환(기본 꺼짐).
3. **분량**: 공백 포함/제외 글자 수, 원고지 매수, 회차/챕터 목표 진행 표시.
4. **저장**: 로컬 프로젝트 폴더에 문서별 파일. 자동저장. 원자적 저장(임시 파일 → rename). 자동/수동 스냅샷(화면 이름: 기록). 휴지통(30일).
5. **설정집**: 인물·장소·용어 + 사용자 분류, 별칭, 본문 자동 강조, 오른쪽 미리보기.
5-1. **기획**: 시놉시스·작품 소개 등 원고 분량에 포함되지 않는 문서.
5-2. **자료**: 이미지, PDF, 링크, 텍스트 스크랩. 프로젝트 폴더로 복사, 가운데 탭·분할 창에서 보기. 자료 조사는 앱 안 브라우저 탭(운영체제 기본 엔진: Windows WebView2, macOS WKWebView)에서 하고 "자료로 보관"으로 담는다. 구글 계정 로그인은 앱 안 브라우저에서 막혀 있어 안 되며, 외부 브라우저로 넘기는 버튼은 두지 않는다(2026-09-28 결정). 휴대폰은 브라우저의 공유로 보관.
5-3. **메모**: 본문 구간·회차·카드·자료·작품에 붙는 댓글형 메모. 답글, 태그, 완료. 메모함에서 모아보기.
6. **가져오기**: txt, md, docx, HWPX. "제1화", "1장", "Chapter 1", 제목 서식 등 패턴 자동 탐지로 트리 생성. 탐지 결과를 미리 보고 수정한 뒤 확정. 옛 HWP는 한글에서 HWPX로 저장 후 가져오기.
7. **내보내기**: txt, 클립보드(회차 단위), docx, HWPX. 원고 서식 프리셋 적용.
8. **서식 설정**: 작성 화면 설정, 원고 서식 프리셋(출판사 투고 A4, 웹소설 플랫폼, 사용자 프리셋).
