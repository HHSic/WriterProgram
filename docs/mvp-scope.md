## 프로젝트 유형

| | 웹소설 | 출판 장편 |
|---|---|---|
| 기본 단위 | 회차 | 챕터 |
| 분량 목표 | 회차당 글자 수 (예: 공백 포함 5,000자) | 전체/챕터 목표, 원고지 매수 |
| 주 출력 | 플랫폼 붙여넣기용 txt/클립보드 | HWPX/docx 원고 |

유형은 용어·기본 템플릿·기본 목표만 바꾸고 내부 데이터 구조는 같다.

## 구조 모델: 트리 + 자동 개요

- **트리 = 저장 단위.** 작품 > 부/권(폴더) > 회차·챕터(문서 파일). 동기화·스냅샷·분량 목표·내보내기 모두 문서 단위.
- **문서 내부 = 자동 개요.** 제목 서식과 장면 구분자(`***`, `◆` 등, 설정 가능)를 자동 탐지해 사이드바 개요로 표시. 클릭 시 해당 위치로 이동.
- **장면은 파일이 아니다.** 장면은 문서 안의 구분자로만 표현한다. 파일 수와 구조 복잡도를 줄이기 위함.
- **이어보기 모드.** 트리에서 여러 문서를 선택하면 하나의 연속 문서처럼 읽고 편집. 저장은 각 문서 파일로 분리.
- **분할/병합.** 커서 위치에서 새 회차·챕터로 분할, 인접 문서 병합.

## v0.1 기능

1. **프로젝트 구조**: 위 구조 모델. 트리 드래그로 순서 변경, 이어보기, 분할/병합.
2. **에디터**: 한글 IME 안정성 최우선. 기본 서식, 집중 모드, 다크 모드, 작품 전체 찾기/바꾸기.
3. **분량**: 공백 포함/제외 글자 수, 원고지 매수, 회차/챕터 목표 진행 표시.
4. **저장**: 로컬 프로젝트 폴더에 문서별 파일. 자동저장. 원자적 저장(임시 파일 → rename). 자동/수동 스냅샷.
5. **설정집**: 인물·장소·용어 카드, 본문에서 카드 열기.
6. **가져오기**: txt, docx. "제1화", "1장", "Chapter 1", 제목 서식 등 패턴 자동 탐지로 트리 생성. 탐지 결과를 미리 보고 수정한 뒤 확정. HWP 사용자는 한글에서 docx/txt로 저장 후 가져오기.
7. **내보내기**: txt, 클립보드(회차 단위), docx, HWPX.
