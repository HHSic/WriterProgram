# 화면 영역과 데이터 설계

작업 화면(S4)의 영역마다 어떤 데이터가 들어가는지, 그 데이터가 어디서 오는지를 정의한다. 화면별 세부 항목은 [screens.md](screens.md).

## 원칙

| 영역 | 역할 | 질문 |
|---|---|---|
| 상단 바 | 작품 전체 상태 | "지금 어느 작품, 어떤 상태인가?" |
| 왼쪽 | 탐색 | "어디로 갈까?" — 작품 안의 모든 것의 목록 |
| 가운데 | 작업 대상 | "지금 무엇을 편집하나?" — 탭으로 여러 개, 보이는 것은 창마다 하나 |
| 오른쪽 | 맥락 | "지금 작업 대상에 딸린 것은?" — 가운데 활성 탭이 바뀌면 내용이 바뀜 |

- 왼쪽은 가운데가 무엇이든 항상 같다.
- 오른쪽은 가운데 활성 탭의 대상 종류에 따라 탭 구성이 달라진다.
- 원본 데이터는 하나다. 같은 데이터를 두 곳에서 편집하지 않는다(예: 설정 카드는 오른쪽에서는 미리보기, 편집은 가운데 탭).

다른 앱과 비교: Scrivener(Binder / Editor / Inspector), Dabble(원고·Story Notes / Editor / Plots·Comments)와 같은 3단 구조. 뮤블식 자유 배치·위젯은 복잡도 때문에 채택하지 않고, 3단 고정 + 탭 + 2분할로 한정한다.

## 데이터 종류

| 데이터 | 설명 | 저장 |
|---|---|---|
| 작품 (Project) | 제목, 유형, 필명, 목표, 원고 서식, 장면 구분자 | `project.json` |
| 부 (Part) | 회차 묶음, 순서 | 폴더 + `project.json`의 순서 |
| 회차·챕터 (Document) | 본문, 제목, **시놉시스**(1~2줄 요약), 상태 라벨, 목표 분량 | 문서 파일 하나 |
| 기획 문서 (Planning Doc) | 시놉시스, 작품 소개, 로그라인, 플롯 구상 등 자유 문서. 원고 분량에 포함 안 됨 | 문서 파일 하나 (`planning/`) |
| 장면 (Scene) | 장면 구분자로 나뉜 구간 | 저장 안 함, 본문에서 계산 |
| 설정 카드 (Card) | 분류, 이름, 별칭, 필드, 서술 | 카드 파일 하나 |
| 설정 분류 (Card Type) | 인물·장소·용어(기본) + 사용자 분류(세력, 아이템, 스킬 등), 분류별 기본 필드 | `project.json` |
| 자료 (Research Item) | 이미지, PDF, 웹 링크, 텍스트 스크랩. 제목, 태그, 출처 | 원본 파일 복사본 + 메타 파일 (`research/`) |
| 메모 (Note) | 아무 곳에나 붙이는 메모·댓글 (아래) | 메모 파일 (문서별 또는 작품) |
| 스냅샷 (Snapshot, 화면 이름: 기록) | 문서 또는 작품 전체의 특정 시점 사본 | `.snapshots/` |
| 휴지통 항목 | 삭제된 문서·카드·자료·메모, 삭제 시각 | `.trash/` (30일 보관) |
| 서식 프리셋 | 원고 서식 묶음 | 작품 또는 앱 설정 |
| 파생 데이터 | 글자 수, 등장 회차, 개요, 비축 수, 검색 색인 | 저장 안 함(캐시만), 원본에서 계산 |

### 상태 라벨 (프로젝트 유형별)

| 라벨 | 뜻 | 유형 |
|---|---|---|
| 초안 | 쓰는 중 | 공통 (기본값) |
| 퇴고 | 고치는 중 | 공통 |
| 완료 | 원고 완성 | 공통 |
| 비축 | 완성, 아직 올리지 않음 | 웹소설 |
| 예약 | 플랫폼에 예약 등록, 예약 날짜(선택) | 웹소설 |
| 연재됨 | 공개됨, 공개 날짜(선택) | 웹소설 |
| 탈고 | 편집자에게 넘긴 최종 원고 | 출판 |
| 1교 · 2교 · 3교 | 교정 단계, 회신 마감일(선택) | 출판 |

- 웹소설 유형은 원고 지도 위에 "비축 N화"를 표시한다(비축 + 예약 라벨 수).
- 출판 유형은 교정 중에 원고 지도의 장마다 "남은 곳"(확인하지 않은 바뀐 곳) 수를 표시한다.

## 메모 (댓글형 메모 통합)

화면 이름은 **메모**다. 한글(HWP)에서 '주석'은 각주·미주를 뜻해서 헷갈리지 않도록 쓰지 않는다([terminology.md](terminology.md)).

"아무 데나 아무렇게나 적는 것"을 하나의 데이터로 통합한다. 차이는 **어디에 붙어 있는가(anchor)** 뿐이다.

| 붙는 곳 | 예 | 만드는 법 |
|---|---|---|
| 본문 구간 | "이 대사 너무 설명조", "복선: 12화에서 회수" | 텍스트 선택 → 메모 달기 (Ctrl+Alt+M) |
| 회차 | "이번 화 퇴고 때 속도 올리기" | 트리 우클릭 또는 오른쪽 메모 탭에서 "이 회차에 메모" |
| 설정 카드 / 자료 | "서하 과거사 아직 미정" | 카드·자료 화면에서 메모 달기 |
| 작품 (어디에도 안 붙음) | 아이디어, 떠오른 장면 | 왼쪽 "메모함"에서 새 메모, 또는 빠른 메모 단축키 |

### 메모 항목

| 필드 | 설명 |
|---|---|
| 내용 | 자유 텍스트 (줄바꿈, 링크 가능) |
| 답글 | 댓글처럼 아래로 이어 쓰기 (나중에 생각을 덧붙이는 용도, 이후 공동 작업·편집자 교정에도 사용) |
| 태그 | 자유 입력 + 기본 제안: 할 일, 복선, 자료조사, 퇴고, 아이디어 |
| 상태 | 열림 / 완료 (완료한 메모는 기본으로 숨김) |
| 색 | 본문 강조 색 (선택) |
| 만든 시각 / 고친 시각 | 자동 |

### 메모 동작

- 본문 메모은 해당 구간에 옅은 밑줄 + 오른쪽 여백에 표시. 클릭 시 오른쪽 메모 탭에서 그 스레드 열림.
- 본문을 고쳐도 메모은 구간을 따라간다. 구간 글자가 모두 지워지면 "고아 메모"으로 회차에 남긴다(삭제하지 않음).
- 회차를 분할·병합하면 본문 메모은 해당 구간을 따라 이동.
- 내보내기: 기본 제외. 옵션으로 docx는 Word 메모, HWPX는 한글 메모로 내보내기(출판사와 교정 주고받기용).
- 트리의 회차 항목에 열린 메모 개수 표시.

## 상단 바

| 위치 | 항목 |
|---|---|
| 왼쪽 | 작품명, 유형, 현재 위치(부 › 회차) |
| 가운데 | 없음 (비워 둠) |
| 오른쪽 | 저장·동기화 상태, 현재 원고 서식 템플릿(클릭해서 변경), 이어보기·집중 모드·분할·내보내기 버튼, 필명/프로필 메뉴(프로젝트 설정, 앱 환경설정) |

- 권한(보기/댓글/편집)과 공유 대상 표시는 공동 작업 기능 도입 시 오른쪽 프로필 옆에 추가한다. v0.1은 로컬 단독 사용이라 자리만 예약.

## 왼쪽: 탐색 영역 (항상 같음)

| 순서 | 구역 | 데이터 | 항목 표시 | 한 번 클릭 | 더블클릭 |
|---|---|---|---|---|---|
| 1 | 검색 | 검색 색인 | 입력창 | 오른쪽 찾기 탭 | - |
| 2 | 원고 | 부 > 회차 | 번호, 제목, 글자 수, 진행 막대, 상태 라벨, 열린 메모 수. 마우스 올리면 시놉시스. 웹소설은 상단에 "비축 N화" | 가운데 활성 탭에서 열기 | 새 탭 |
| 2-1 | (부 항목) | 부 | 부 제목, 회차 수 | 접기/펼치기 | 개요 표로 열기 |
| 3 | 기획 | 기획 문서 | 문서 이름 목록 | 가운데 활성 탭에서 열기 | 새 탭 |
| 4 | 설정집 | 카드, 분류 | 분류별 개수, 펼치면 카드 이름. 분류 추가 버튼 | 오른쪽 미리보기 | 새 탭 (편집) |
| 5 | 자료 | 자료 항목 | 종류 아이콘(이미지/PDF/링크/텍스트), 제목, 태그 필터 | 오른쪽 미리보기 | 새 탭 (보기) |
| 6 | 메모함 | 작품 메모 + 모든 열린 메모 | 개수, 태그 필터 | 가운데에 메모 목록 | - |
| 7 | 휴지통 | 휴지통 항목 | 개수 (맨 아래 고정) | 가운데에 휴지통 목록 | - |

## 가운데: 작업 대상

| 대상 | 들어오는 경로 | 내용 |
|---|---|---|
| 회차 에디터 | 트리에서 회차 클릭 | 본문 편집, 회차 제목·시놉시스 편집 |
| 이어보기 | 트리에서 여러 회차 선택 → 이어보기 | 여러 회차 연속 편집 |
| 개요 표 | 부 더블클릭, 또는 부 우클릭 → 개요 표 | 부 안의 회차를 표로: 번호, 제목, 시놉시스, 상태, 글자 수/목표, 열린 메모 수. 셀에서 바로 편집(제목·시놉시스·상태), 행 드래그로 순서 변경, 행 클릭으로 회차 열기 |
| 기획 문서 | 기획에서 문서 클릭 | 회차 에디터와 같은 에디터 (분량 목표·상태 라벨 없음) |
| 카드 편집 | 설정 카드 더블클릭, 미리보기의 "편집" | 카드 필드·서술 편집 |
| 자료 보기 | 자료 더블클릭 | 이미지 뷰어 / PDF 뷰어 / 링크(제목·주소·메모, 브라우저로 열기) / 텍스트 스크랩 편집 |
| 메모 목록 | 메모함 클릭 | 메모 목록 (붙은 곳별 묶기, 태그·상태 필터), 작품 메모 편집 |
| 휴지통 목록 | 휴지통 클릭 | 삭제 항목, 복원 / 영구 삭제 |
| 기록 비교 | 오른쪽 기록 탭에서 "지금과 비교" | 지금 원고와 기록을 나란히 |
| 교정본 비교 | "마감" 모드에서 교정본 가져오기 | 보낸 원고 대비 바뀐 곳(지운 글자 취소선, 넣은 글자 밑줄), 편집자 메모, 받아들이기/되돌리기 |

### 가운데 탭

가운데 작업 대상은 탭으로 여러 개 열어 둘 수 있다. 오른쪽 맥락 영역은 **활성 탭**을 따른다.

- 탭 하나 = 작업 대상 하나. 탭에 종류 아이콘 + 이름.
- 탭이 하나뿐이면 탭 줄을 숨긴다(작가용 앱의 단순함 유지).
- 같은 대상은 탭 하나만. 이미 열린 대상을 다시 열면 그 탭으로 이동.
- 자동 저장이라 "저장 안 됨" 표시는 없음. 저장 실패 시에만 탭에 경고 표시.
- 탭 순서 드래그, 가운데 클릭으로 닫기, Ctrl+Tab 전환, 닫은 탭 다시 열기(Ctrl+Shift+T).
- 작품을 다시 열면 마지막 탭 구성과 커서 위치 복원.
- 넘치는 탭은 오른쪽 끝 "더 보기" 목록으로.

### 분할 (참조 창 대체)

- 가운데를 좌우(또는 위아래) 두 창으로 나눌 수 있다. 각 창은 자기 탭 줄을 가진다.
- 두 창 모두 편집 가능. 같은 회차를 양쪽에 열 수도 있고(긴 회차의 앞뒤를 동시에 보기), 내용은 실시간 동기화.
- 오른쪽 맥락 영역은 **포커스가 있는 창**의 활성 탭을 따른다.
- 창마다 읽기 전용 잠금 토글(참고용으로 띄운 창에서 실수로 고치는 것 방지).
- 자료(PDF·이미지)를 한쪽에 띄우고 원고를 쓰는 용도로도 사용.
- 최대 2분할 (v0.1).

### 클릭 동작 규칙

| 동작 | 결과 |
|---|---|
| 왼쪽에서 회차·기획 문서 클릭 | 가운데 활성 탭에서 열기 (활성 탭이 같은 종류면 교체, 아니면 새 탭) |
| 왼쪽에서 회차·기획 문서 Ctrl+클릭 / 더블클릭 | 새 탭으로 열기 |
| 왼쪽에서 설정 카드·자료 한 번 클릭 | 가운데 그대로, 오른쪽에 미리보기 |
| 왼쪽에서 설정 카드·자료 더블클릭 | 새 탭으로 열기 |
| 본문의 강조된 이름 클릭 | 오른쪽에 카드 미리보기 |
| 오른쪽 미리보기의 "편집" / "열기" | 새 탭으로 열기 |
| 뒤로 / 앞으로 (Alt+← / Alt+→) | 탭 안의 이동 기록, 커서 위치 포함 |

## 오른쪽: 맥락 영역 (가운데 활성 탭에 따라 바뀜)

| 가운데 대상 | 탭 구성 (굵은 글씨 = 기본으로 열리는 탭) |
|---|---|
| 회차 에디터 / 이어보기 | **개요** · 메모 · 등장 설정 · 기록 · 찾기 |
| 기획 문서 | **개요** · 메모 · 기록 · 찾기 |
| 개요 표 | **선택한 회차 요약** (시놉시스, 첫 문단, 열린 메모) · 찾기 |
| 카드 편집 | **등장 위치** (회차별 문맥 목록) · 메모 · 관련 카드 |
| 자료 보기 | **정보** (출처, 태그, 추가 시각) · 메모 · 연결된 회차 |
| 메모 목록 | **선택한 메모 상세** (답글, 붙은 곳으로 이동) |
| 휴지통 / 기록 비교 | 없음 (오른쪽 패널 접힘) |

미리보기(설정 카드·자료 한 번 클릭)는 현재 탭 구성 위에 임시로 열리고, 닫으면 원래 탭으로 돌아간다.

### 회차 에디터일 때 탭별 데이터

| 탭 | 데이터 | 표시 | 동작 |
|---|---|---|---|
| 개요 | 장면(파생) + 회차 시놉시스 | 맨 위 시놉시스(편집 가능), 장면 번호, 첫 문장, 글자 수, 현재 장면 강조 | 클릭 이동 |
| 메모 | 이 회차의 본문 메모 + 회차 메모 | 스레드 목록, 본문 순서대로, 완료 숨김 토글 | 클릭 시 본문 구간 이동, 답글, 완료 |
| 등장 설정 | 이 회차에 이름·별칭이 나온 카드(파생) | 카드 요약 (이름, 분류, 핵심 필드 3개) | 클릭 시 미리보기, "편집" 시 새 탭 |
| 기록 | 이 회차의 기록(스냅샷) | 시각, 종류, 글자 수 변화 | 미리보기, 지금과 비교, 이 때로 되돌리기 |
| 찾기 | 검색 결과 | 회차별 묶음 + 문맥 | 이동, 바꾸기 |

## 모바일 대응

| 상단 바 | 화면 상단 제목 줄 + 더 보기 메뉴 |
