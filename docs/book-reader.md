# 앱 안에서 책 미리보기

작업 화면 위쪽의 **책 미리보기**를 연다. 지금 편집 중인 원고에서 시작하고, 기획·설정집·메모를 보고 있었다면 첫 원고부터 읽는다.
본문을 불러오기 전에 저장을 마치며, 저장이나 읽기가 실패하면 오류와 다시 시도 버튼을 표시한다.
잠긴 원고도 읽을 수 있다. 읽기 화면은 원고를 수정하지 않는다.

- **자동**: 미리보기 영역이 좁으면 한 쪽, 넓으면 두 쪽.
- **휴대폰**: 선택한 종이 크기의 한 쪽 미리보기.
- **PC**: 선택한 종이 크기의 두 쪽을 나란히 표시. 좁은 화면에서는 같은 두 쪽을 축소한다.
- **목차**: 작품 순서대로 모든 원고를 선택. 한 번에 한 원고만 불러온다.
- **이전·다음 / ←·→ / PageUp·PageDown / 좌우 밀기**: 쪽 넘기기. 회차 끝에서 다음 회차로, 시작에서 이전 회차의 마지막 쪽으로 이어진다.
- **오른쪽 미리보기 설정**: A4·A5·B5 또는 가로·세로 mm를 직접 입력한다. 기본은 A5(148 × 210mm)이며 한 쪽 기준 크기다. 최소 20mm, 소수 입력과 가로·세로 바꾸기를 지원한다. 크기에 따라 본문을 다시 나누고 읽던 쪽을 유지한다.
- **글자 크기·배경**: 1px부터 최대 제한 없이 직접 입력, 종이·밝게·어둡게. 종이 크기와 함께 이 기기에 저장한다. [계정 로그인](accounts.md)을 하면 이 설정은 계정의 다른 기기에도 적용한다. 휴대폰/PC 선택은 기기별이다. 원고는 바꾸지 않는다.
- **전체화면**: 오른쪽 버튼으로 앱 창을 전체화면으로 전환한다. Esc는 먼저 전체화면에서 나가며, 다시 Esc를 누르면 미리보기를 닫는다. 닫을 때 미리보기에서 확장한 창 상태를 복원한다. 브라우저 미리보기에서는 브라우저 전체화면을 사용한다.

종이 크기·글자 크기·한 쪽/두 쪽 구성을 바꾸거나 글꼴이 로드되면 쪽 수를 다시 계산한다. 96px/inch 기준으로 종이와 본문을 배치한 뒤 화면에 들어가도록 축소하므로, 전체화면 전환은 쪽 수를 바꾸지 않는다(자동 모드에서 한 쪽/두 쪽이 전환되는 경우 제외). 화면에 보이는 mm 크기는 모니터의 실제 물리적 크기를 뜻하지 않는다.
쪽 번호는 현재 회차 기준이며 한글·Word 내보내기 쪽 수와 별개다.
한글, 유니코드 이모티콘, 줄바꿈, 빈 문단, 장면 나눔, 굵게·기울임·취소선·밑줄·글자색·문단 정렬·쪽 나눔을 표시한다.
본문은 React 텍스트 노드로 표시하고 원고에 적힌 HTML은 실행하지 않는다.

현재 배포 설정은 Windows 설치판이다. 이 읽기 화면은 앱 내부 기능이며 Android·iOS 설치판 또는 배포용 전자책 파일을 생성하지 않는다.
드라이브 링크 공유는 기존 DOCX 읽기용 사본을 사용한다.

구현: `app/src/workspace/ReaderDialog.tsx`, `app/src/lib/book.ts`, `app/src/styles/reader.css`.
시험: `ReaderDialog.test.tsx`에서 저장 실패, 회차 이동, 홀수 쪽, 좁은 화면 재계산, 문자 보존과 늦은 응답을 검사한다.
