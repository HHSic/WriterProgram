# 앱 안에서 책 미리보기

작업 화면 위쪽의 **책 미리보기**를 연다. 지금 편집 중인 원고에서 시작하고, 기획·설정집·메모를 보고 있었다면 첫 원고부터 읽는다.
본문을 불러오기 전에 저장을 마치며, 저장이나 읽기가 실패하면 오류와 다시 시도 버튼을 표시한다.
잠긴 원고도 읽을 수 있다. 읽기 화면은 원고를 수정하지 않는다.

- **자동**: 실제 읽기 영역이 좁으면 한 쪽, 넓으면 두 쪽.
- **휴대폰**: 폭을 390px 이내로 맞춘 한 쪽 미리보기.
- **PC**: 넓은 화면에서 두 쪽을 나란히 표시. 창이 좁으면 한 쪽으로 돌아간다.
- **목차**: 작품 순서대로 모든 원고를 선택. 한 번에 한 원고만 불러온다.
- **이전·다음 / ←·→ / PageUp·PageDown / 좌우 밀기**: 쪽 넘기기. 회차 끝에서 다음 회차로, 시작에서 이전 회차의 마지막 쪽으로 이어진다.
- **글자 크기·배경**: 14~30px, 종이·밝게·어둡게. 이 기기의 읽기 설정에만 저장한다.

화면 크기와 글자 크기를 바꾸거나 글꼴이 로드되면 쪽 수를 다시 계산한다.
쪽 번호는 현재 회차 기준이며 한글·Word 내보내기 쪽 수와 별개다.
한글, 유니코드 이모티콘, 줄바꿈, 빈 문단, 장면 나눔, 굵게·기울임·취소선·밑줄을 표시한다.
본문은 React 텍스트 노드로 표시하고 원고에 적힌 HTML은 실행하지 않는다.

현재 배포 설정은 Windows 설치판이다. 이 읽기 화면은 앱 내부 기능이며 Android·iOS 설치판 또는 배포용 전자책 파일을 생성하지 않는다.
드라이브 링크 공유는 기존 DOCX 읽기용 사본을 사용한다.

구현: `app/src/workspace/ReaderDialog.tsx`, `app/src/lib/book.ts`, `app/src/styles/reader.css`.
시험: `ReaderDialog.test.tsx`에서 저장 실패, 회차 이동, 홀수 쪽, 좁은 화면 재계산, 문자 보존과 늦은 응답을 검사한다.
