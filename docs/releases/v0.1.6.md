문서 도구를 상단 탭으로 모으고, 작성 화면의 쪽 보기를 세로로 이어서 표시합니다.

- **편집·서식·보기·쪽·검토 도구**: 저장·실행 취소, 문자표·장면 나눔, 제목·부제목·소제목, 글자 꾸밈·색·정렬·들여쓰기, 화면 글꼴·크기·자간, 쪽 보기·눈금자·문단 부호, 용지·방향·여백·머리말·꼬리말, 문서 이력·메모·교정본을 탭에서 사용합니다. 도구줄은 접거나 가로로 스크롤할 수 있습니다.
- **문서 이력**: 검토 → 문서 이력 관리에서 자동 기록, 직접 보관, 변경 문단 비교, 복원을 사용합니다. 목록에서 기록을 열고 ‘지금 글과 비교’를 누르면 추가·삭제·수정된 본문을 나란히 보여줍니다. 기준 원고를 다른 기록으로 바꿔 과거 기록 두 개도 비교할 수 있습니다. 복원 전에는 지금 글을 먼저 보관합니다. 잠기거나 동시 수정 충돌이 있는 문서는 비교만 가능합니다.
- **간결한 상단 화면**: 중복된 빠른 서식 버튼을 도구줄로 모으고, 창이 좁을 때 읽기·공유·창 기능을 작업 메뉴에서 사용합니다. 도구줄의 마지막 탭과 접힘 상태를 기억하고, 방향키로 탭을 이동할 수 있습니다.
- **슬래시·우클릭 서식**: 문단 첫머리에 `/`를 입력해 명령을 찾고 Enter로 적용합니다. 글을 드래그해 선택한 뒤 우클릭으로 제목 스타일·정렬·글자색·들여쓰기·메모를 설정합니다. 제목 스타일은 작품 파일과 Word·HWPX 내보내기에 보존합니다.
- **선택적인 시놉시스**: 새 문서에는 시놉시스 칸을 표시하지 않습니다. `/시놉시스 추가`로 넣고 삭제 버튼이나 `/시놉시스 삭제`로 제거합니다. 기존 내용이 있는 문서는 계속 표시합니다.
- **세로 쪽 보기**: 작성 화면에서 1쪽 아래에 2쪽·3쪽이 이어지고 스크롤로 이동합니다. 긴 문단과 빈 줄, 직접 넣은 쪽 나눔을 반영하며 페이지 간격은 원고 내용에 저장하지 않습니다. 책 미리보기의 넘김 방식은 그대로입니다.
- **인물·장소 자동 찾기**: 설정집의 자동 찾기 또는 검토 탭에서 현재 문서·전체 원고의 후보와 등장 문맥을 확인하고 선택한 이름만 등록합니다. 기기 안에서 분석하며, 등록된 이름과 별칭의 중복을 막습니다. 문맥을 이용한 후보 제안이므로 결과를 확인해 주세요.
- **문서 메모 가져오기**: 일반 Word·HWPX·HWP 가져오기에서도 문서에 달린 메모를 메모함에 보존합니다. Word·HWPX의 작성자·날짜와 제공되는 인용문을 함께 보관하며, HWP 메모 목록의 본문을 읽습니다. 파일마다 첫 번째로 가져오는 문서에 문서 메모로 연결하고, 가져오기 옵션으로 제외할 수 있습니다. 표·그림 등이 빠진 위치에 남기는 안내 메모는 별도 옵션입니다.
- **웹 패널 하얀 화면 수정**: 웹 패널과 겹치지 않는 메뉴는 웹 화면을 숨기지 않습니다. Windows에서는 겹치는 메뉴·대화상자가 열린 동안 웹 화면의 미리보기 이미지를 유지하고 닫으면 기존 웹뷰를 다시 표시합니다. 이미지는 메모리에만 보관합니다.

화면 글꼴·크기·자간은 이 기기의 작성 화면 설정입니다. 실제 용지·내보내기 서식은 쪽 → 편집 용지에서 설정합니다. 화면의 페이지 수는 한글·Word가 계산한 페이지 수와 다를 수 있습니다. Windows x64 설치판이며 기존 앱의 새 버전 확인으로 업데이트할 수 있습니다.
