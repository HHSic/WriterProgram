계정 로그인과 개인 설정 자동 동기화를 추가했습니다.

- 시작 화면이나 **보기 → 보기 설정 → 계정·설정 동기화**에서 Google·Kakao, 이메일·비밀번호 앱 계정, 등록된 회사·학교 SAML SSO로 로그인할 수 있습니다.
- 로그인하면 글꼴·글자 크기·자간·화면 색·쪽 보기·도구줄·책 미리보기 설정을 자동 적용합니다. 오프라인 변경은 기기에 보관하며, 다른 기기의 수정과 항목별로 합쳐 저장합니다. 로그아웃하면 로그인 전의 기기 설정으로 돌아갑니다.
- 로그인 토큰은 네이티브 앱의 자격 증명 저장소에서 관리하며 설정을 계정별로 분리합니다.

운영자는 Supabase 프로젝트와 설정 DB, 로그인 제공자를 먼저 등록해야 합니다. Google·Kakao·이메일 로그인과 설정 저장은 Free 플랜으로 시작할 수 있고, SAML SSO는 Pro 이상입니다. 연결 정보가 없는 설치판에서는 서버 연결 설정을 먼저 입력합니다. [운영자 설정 안내](https://github.com/HHSic/WriterProgram/blob/main/docs/accounts.md)

Windows x64 설치판이며 기존 앱의 새 버전 확인으로 업데이트할 수 있습니다.
