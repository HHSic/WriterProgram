책 미리보기의 종이 크기와 전체화면을 추가했습니다.

- 미리보기 오른쪽에서 A4·A5·B5를 고르거나 한 쪽의 가로·세로를 mm로 직접 입력합니다. 가로·세로 바꾸기도 지원합니다.
- 선택한 종이 크기로 본문을 다시 나누고 화면에 맞춰 축소합니다. 읽던 쪽과 글자 크기를 유지하며, 종이 크기 설정은 이 기기에 저장합니다.
- 전체화면 버튼으로 앱 창을 확장합니다. Esc로 전체화면을 나가고, 미리보기를 닫으면 미리보기에서 확장한 창을 복원합니다.
- 글자 크기는 편집 화면과 미리보기 모두 1px부터 최대 제한 없이 설정합니다.

화면의 쪽수는 원고의 한글·Word 내보내기 쪽수와 별개입니다. Windows x64 설치판이며 기존 앱의 새 버전 확인으로 업데이트할 수 있습니다.
