드라이브 연결을 앱 안에서 설정할 수 있습니다.

- **기기 간 맞추기 → 드라이브 연결 마법사**에서 Google Drive·OneDrive·Dropbox를 선택하고 연결합니다.
- 회사별 앱 등록 페이지를 열고 필요한 권한·앱 유형·돌아오는 주소를 단계별로 안내합니다.
- 발급된 앱 ID와 필요한 등록 정보를 입력하면 이 기기에 저장합니다. `drive-apps.json` 파일을 직접 만들 필요가 없습니다.
- 등록 정보가 준비된 드라이브는 바로 브라우저 로그인으로 이동합니다. 로그인 후 연결된 계정을 확인할 수 있습니다.
- 저장·로그인 실패 시 입력을 유지하고 오류를 표시합니다. 로그인 취소와 재시도를 지원하며 다른 드라이브의 기존 등록 정보를 보존합니다.

각 회사의 관리 페이지에서 앱을 등록하는 작업은 처음 한 번 직접 진행해야 합니다. 연결 완료 후 작품 설정에서 ‘드라이브와 맞추기’를 시작하거나 ‘공유’를 이용하세요.

Windows x64 설치판입니다. 기존 앱은 보기 설정의 새 버전 확인에서 저장 후 업데이트할 수 있습니다.
