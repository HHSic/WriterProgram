화면 기능을 탭 아래 도구줄로 모아 상단을 단순하게 정리했습니다.

- **보기 탭**: 쪽 보기, 눈금자, 문단 부호, 보기 설정, 나눠 보기, 집중 모드, 오른쪽 패널, 웹 보기, 책 미리보기, 소리 내어 읽기를 탭 바로 아래에서 사용합니다. 나눠 보기는 좌우·위아래 방향과 닫기를 선택할 수 있습니다.
- **편집 탭**: 작품 파일 저장, 원고 가져오기, 내보내기, 공유를 파일·공유 묶음으로 모았습니다.
- **맨 위 문서 줄**: 문서 위치, 저장 상태, 패널 버튼과 작업 메뉴만 표시합니다. 도구줄을 접었을 때는 작업 메뉴와 기존 단축키로 기능을 사용할 수 있습니다.

Windows x64 설치판이며 기존 앱의 새 버전 확인으로 업데이트할 수 있습니다.
