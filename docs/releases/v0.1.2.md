작품 파일 저장, 드라이브 링크 공유, 앱 안의 책 미리보기를 추가했습니다.

- 작품 전체를 `.wpm` 파일 하나로 저장하고 다시 열 수 있습니다. 원고·기획·설정집·메모·기록이 함께 보관되며, 설치판에서 파일 연결을 지원합니다.
- 연결한 Google Drive·OneDrive·Dropbox 계정으로 선택한 원고의 읽기용 DOCX 사본과 공유 링크를 만들고 공유를 종료할 수 있습니다. 실제 계정 정책에 따라 공개 링크 생성이 제한될 수 있습니다. Dropbox는 공유 권한 추가 후 계정을 다시 연결해야 할 수 있습니다.
- 책 미리보기에서 휴대폰 한 쪽·PC 두 쪽 보기, 목차 이동, 글자 크기와 배경 조절, 방향키·터치 넘김을 지원합니다.
- 문자표에 텍스트 이모티콘과 유니코드 표정·기호를 추가했습니다.
- 자동 업데이트는 새 버전을 알려 주고, 원고와 작품 파일을 저장한 뒤 서명을 확인하여 설치합니다.

이번 설치 파일은 Windows x64용입니다. 책 미리보기의 휴대폰 화면 선택은 앱 내부 미리보기이며 Android·iOS 설치판은 포함하지 않습니다.
