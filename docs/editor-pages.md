# 편집 화면의 페이지와 서식

상단 ‘쪽 보기’ 또는 ‘보기 설정 → 페이지 단위로 보기·편집하기’로 연속
스크롤과 쪽 단위 편집을 전환합니다. ‘이전 쪽·다음 쪽’과 쪽수 표시로 이동합니다.
용지의 비율·여백은 작품의 원고 서식을 따릅니다. 연속형 원고 서식은 A4와
한글 기본 여백을 사용합니다. 화면 글꼴·크기·줄 간격·자간은 보기 설정을
따르므로 HWPX/DOCX 출력 쪽수와 정확하게 일치하는 인쇄 교정 기능은 아닙니다.

Ctrl+Enter로 커서에서 쪽을 나눕니다. 상단 ‘서식’ 메뉴에서 쪽 나눔을 넣거나
해당 문단 앞의 나눔을 없앨 수 있습니다. Enter로 만든 빈 줄은 실제 공간으로
남아 쪽이 차면 다음 쪽으로 넘어갑니다. 별도의 빈 줄 개수 규칙은 없습니다.
페이지 전환은 편집 문서를 분할하거나 글을 수정하지 않으며 한글 조합 중에
다시 측정하지 않습니다. 서식·쪽 나눔은 저장하고 HWPX/DOCX로 내보냅니다.

상단 ‘서식’에서 왼쪽·가운데·오른쪽·양쪽 정렬과 글자색을 고릅니다.
Ctrl+E는 가운데, Ctrl+L은 왼쪽, Ctrl+R은 오른쪽 정렬입니다. 편집 도구줄은
‘보기 설정 → 편집 도구줄 → 늘 보이기’로 표시합니다. 여기에서 임의 RGB
색상을 고르거나 기본 글자색으로 되돌릴 수 있습니다.

나눠보기의 탭은 같은 창 안에서 정렬하거나 다른 창의 탭 줄·본문으로
끌어 옮깁니다. 다른 창으로 옮기기 전 저장이 실패하면 이동을 멈춥니다.
탭 오른쪽 끝으로 제목 너비를, 창 사이 경계로 두 창의 크기를 조절합니다.
두 번 누르면 기본 크기로 돌아갑니다. 조절 손잡이는 방향키도 지원합니다.

개요의 장면을 누르면 빈 문단·앞쪽 빈칸을 건너뛴 첫 글자가 해당 편집 창
맨 위에 옵니다. 마지막 장면에도 필요한 아래쪽 공간을 확보합니다.
Ctrl+S는 원고·제목·설정집·메모와 연결된 WPM 파일의 대기 중인 저장을
완료합니다. 상단과 하단에서 ‘저장 중·저장됨·저장하지 못함’을 확인할 수
있고 수동 저장은 완료 후 알림을 띄웁니다.

작성 화면과 책 미리보기의 글자 크기는 1px부터 숫자로 입력할 수 있으며 최대 제한이 없습니다.
