# 화면 설계 (v0.1)

v0.1 기능([mvp-scope.md](mvp-scope.md))을 화면 단위로 나누고, 화면마다 들어갈 항목을 정리한다. 화면 문구는 [terminology.md](terminology.md) 기준.

## 화면 지도

```
시작 화면 ─┬─ 새 작품 만들기
           ├─ 가져오기 마법사
           └─ 작업 화면 (에디터) ─┬─ 이어보기 모드
                                   ├─ 집중 모드
                                   ├─ 분할 창
                                   ├─ 개요 표
                                   ├─ 기획 문서
                                   ├─ 설정집
                                   ├─ 자료
                                   ├─ 작품 전체 찾기/바꾸기
                                   ├─ 기록 (스냅샷)
                                   ├─ 내보내기
                                   ├─ 교정본 주고받기 (보내기, 목록, 검토 탭)
                                   └─ 프로젝트 설정 (원고 서식 포함)
앱 환경설정 (어디서나)
```

| ID | 화면 | 형태 | 플랫폼 |
|---|---|---|---|
| S1 | 시작 화면 | 전체 화면 | 데스크톱 / 모바일 |
| S2 | 새 작품 만들기 | 대화상자 | 데스크톱 / 모바일 |
| S3 | 가져오기 마법사 | 대화상자 (3단계) | 데스크톱 |
| S4 | 작업 화면 | 전체 화면 | 데스크톱 / 모바일 |
| S5 | 이어보기 모드 | S4 변형 | 데스크톱 |
| S6 | 집중 모드 | S4 변형 | 데스크톱 / 모바일 |
| S7 | 분할 창 | S4 가운데 2분할 | 데스크톱 (모바일은 시트) |
| S8 | 설정집 | S4 가운데 탭 + 오른쪽 미리보기 | 데스크톱 / 모바일 |
| S9 | 찾기/바꾸기 | S4 보조 패널 | 데스크톱 |
| S10 | 기록 (스냅샷) | S4 보조 패널 + 비교 화면 | 데스크톱 |
| S11 | 내보내기 | 대화상자 | 데스크톱 |
| S12 | 프로젝트 설정 | 대화상자 (탭) | 데스크톱 |
| S13 | 앱 환경설정 | 대화상자 (탭) | 데스크톱 / 모바일 |
| S14 | 개요 표 | S4 가운데 탭 | 데스크톱 |
| S15 | 기획 문서 | S4 가운데 탭 | 데스크톱 / 모바일 |
| S16 | 자료 | S4 가운데 탭 + 오른쪽 미리보기 | 데스크톱 / 모바일 |
| S17 | 마감 (웹소설: 연재 / 출판: 교정) | 작업 모드 | 데스크톱 |
| S18 | 교정본 주고받기 (보내기, 보낸 원고 목록, 교정본 검토) | 대화상자 2개 + S4 가운데 탭 | 데스크톱 |

영역별 데이터·클릭 규칙·탭 동작은 [layout-data.md](layout-data.md).

## S1. 시작 화면

- **최근 작품 목록** (카드): 작품명, 유형(웹소설/출판), 총 글자 수, 마지막 수정 시각, 저장 위치(경로 줄임).
- **버튼**: 새 작품, 폴더에서 열기, 원고 가져오기…(txt/md/docx/hwpx → S3을 새 작품 모드로).
- **카드 메뉴**: 열기, 폴더 위치 열기, 목록에서 제거(파일은 삭제 안 함).
- **빈 상태**: 첫 실행 시 "새 작품" / "기존 원고 가져오기" / "폴더에서 열기" 버튼만 크게.
- **오류 상태**: 경로를 찾을 수 없는 작품은 흐리게 표시 + "위치 다시 지정".
- **작품 구조 파일이 손상됨** (`screens/RecoverDialog.tsx`): 열기에서 project.json이 깨졌으면 오류 한 줄 대신 "작품을 열 수 없음" 창. "작품 구조 파일(project.json)이 손상되어 열 수 없습니다. 원고 파일은 그대로 있습니다." 아래에 되살리는 방법을 고른다: (다른 기기 사본이 있으면 맨 위에) 다른 기기 사본으로 되돌리기(저장 시각, 부·회차 수) / 가장 최근 백업으로 되돌리기(백업 날짜, 부·회차 수, "백업 뒤에 생긴 회차는 마지막 부 끝에 붙입니다", 없으면 흐리게 "백업이 없습니다") / 원고 파일로 구조 다시 만들기(회차 파일 수, 부 나눔과 작품 설정은 처음 값으로) / 닫기. 어느 쪽이든 손상된 파일은 `project.json.damaged-시각`으로 남긴다고 알린다.

## S2. 새 작품 만들기

| 항목 | 입력 | 기본값 |
|---|---|---|
| 작품 제목 | 텍스트 (필수) | - |
| 유형 | 웹소설 / 출판 장편 | 웹소설 |
| 저장 위치 | 폴더 선택 | 문서/WriterProgram |
| 연재 플랫폼 (웹소설) | 정하지 않음 / 문피아 / 노벨피아 / 카카오페이지 / 네이버 / 리디 | 정하지 않음. 고르면 그 최소 분량이 목표로 들어가고 세는 법을 따름 ([platforms.md](platforms.md)) |
| 회차·챕터 목표 분량 | 숫자 + 공백 포함/제외 (플랫폼을 고르면 "○○ 기준") | 웹소설 5,000자(공백 포함), 출판 없음 |
| 원고 서식 프리셋 | 목록 | 유형에 따라 자동 |
| 첫 구조 | 1부 + 1화 자동 생성 여부 | 켜짐 |

버튼: 만들기, 취소.

## S3. 가져오기 마법사

1. **파일 선택**: txt / md / docx / hwpx, 여러 파일 가능(파일 하나 = 회차 하나로 가져오기 옵션). 인코딩 자동 감지(UTF-8, EUC-KR), 수동 변경 가능.
2. **구조 탐지 미리보기**:
   - 왼쪽: 탐지된 트리 (부 / 회차 / 제목, 회차별 글자 수).
   - 오른쪽: 원문 미리보기, 분할 위치에 선 표시. 선을 클릭해 제거, 원하는 줄에서 "여기서 나누기".
   - 탐지 규칙 선택: "제N화", "N화", "N장", "Chapter N", "#N", 제목 서식(docx·hwpx), 사용자 정규식.
   - 줄바꿈 해석: 줄바꿈 하나 = 문단 / 빈 줄 = 문단 구분.
   - 장면 구분자 탐지: `***`, `◆`, `* * *` 등 → 앱의 장면 구분으로 변환 여부.
   - 아주 큰 회차(공백 포함 5만 자 넘음): 목록 위 안내 한 문단 "‘…’이 공백 포함 N자로 아주 깁니다…" + "자동으로 나누기"(이미 자동이면 "패턴 쓰기"). 큰 회차 하나는 쓰는 동안 화면을 느리게 한다(feature-gap-report.md 3.3).
3. **확정**: 새 작품으로 만들기 또는 현재 작품의 특정 부에 추가. 요약(회차 N개, 총 N자) 표시.
   - 시작 화면에서 열었을 때(새 작품 모드): 창 제목 "기존 원고 가져오기", 첫 단계에 "원래 파일은 그대로 둡니다" 안내, 마지막 단계에서 작품 제목(첫 파일 이름으로 채움)·유형·저장 위치를 묻고 버튼은 "새 작품 만들기". 만든 작품의 1부에 회차를 넣고 연다. 가져오기가 실패하면 빈 작품을 열고 그 사실을 알린다.

## S4. 작업 화면

### 상단 바
- 왼쪽: 작품명, 유형, 현재 위치 (부 › 회차)
- 오른쪽:
  - 저장·동기화 상태: 저장됨 / 저장 중 / 저장 실패(빨강, 클릭 시 원인과 재시도)
  - 원고 서식 템플릿 (현재 프리셋 이름, 클릭해서 변경)
  - 버튼: 이어보기, 집중 모드, 분할, 내보내기
  - 필명/프로필 메뉴: 프로젝트 설정, 앱 환경설정, 지금 원고 보관
  - 권한·공유 자리 (공동 작업 도입 시, v0.1 없음)

### 왼쪽: 탐색
위에서부터 순서대로.
1. 검색 입력 (작품 전체 찾기 열기)
2. **원고**
   - 웹소설 유형: 맨 위에 "비축 N화"
   - 부 (접기/펼치기, 회차 수, 더블클릭 시 개요 표)
   - 회차 항목: 번호, 제목, 글자 수, 목표 진행 막대, 상태 라벨, 열린 메모 수. 마우스를 올리면 시놉시스
   - 드래그로 순서 변경, 부 사이 이동, 여러 개 선택(Shift/Ctrl)
   - 회차 우클릭 메뉴: 이름 변경, 새 회차(위/아래), 복제, 다음 회차와 병합, 상태 변경, 목표 분량 변경, 분할 창으로 열기, 이 회차에 메모, 휴지통으로
   - 부 우클릭 메뉴: 이름 변경, 개요 표로 보기, 이어보기, 새 회차, 휴지통으로
3. **기획**: 기획 문서 목록 (시놉시스, 작품 소개 등), 새 기획 문서
4. **설정집**: 분류별(인물 / 장소 / 용어 / 사용자 분류) 개수, 펼치면 카드 이름, 분류 추가
5. **자료**: 이미지 / PDF / 링크 / 텍스트 스크랩, 자료 추가(파일 끌어 놓기, 링크 붙여넣기)
6. **메모함**: 작품 메모 + 모든 열린 메모 모아보기 (개수)
7. **휴지통**: 맨 아래 고정 (삭제한 회차·문서·카드·자료·메모, 30일 보관)
- 하단: 새 회차 버튼

### 가운데: 탭 + 에디터
- 탭 줄 (탭이 2개 이상일 때만 표시), 분할 시 창마다 탭 줄
- 회차 제목 (편집 가능)
- 회차 시놉시스 (제목 아래 한두 줄, 접기 가능)
- 본문: 문단, 장면 구분자, 설정집 이름 강조(클릭 시 카드), 한글 조합 표시
- 서식 도구 (선택 시 떠오르는 작은 도구줄): 굵게, 기울임, 밑줄, 취소선, 방점(선택), 장면 구분 넣기
- 커서 위치에서 우클릭: 여기서 새 회차로 나누기, 설정집 카드 만들기(선택한 단어로), 메모 달기
- 본문 메모: 구간에 옅은 밑줄 + 오른쪽 여백 표시
- 소리 내어 읽기 (퇴고용, 회차 머리의 스피커 버튼 · Ctrl+Shift+R · 터치 화면은 편집 도구줄): 커서가 있는 문장부터 끝까지, 고른 글이 있으면 그 글만 읽는다. 읽는 문장을 칠하고 화면을 따라 내린다. 장면 나눔 표시는 잠깐 쉼. 본문 아래 작은 막대에 읽는 중 / 일시정지 / 계속 / 멈춤 / 빠르기(0.7~1.5배). 글을 고치거나 다른 탭으로 가면 멈추고, 멈춤(Esc)은 커서를 읽던 문장 앞에 둔다. 목소리와 빠르기는 보기 설정. 한국어 목소리가 없으면 영어 목소리로 읽지 않고 "Windows 설정 → 시간 및 언어 → 음성"에서 설치하는 방법을 알린다.
- 빠른 이동 스크롤바: 회차 눈금, 드래그 시 회차 말풍선
- 긴 원고 로딩 자리표시 (mvp-scope.md "긴 원고 탐색과 로딩")

### 오른쪽: 맥락 패널 (접기 가능, 탭)
가운데 대상에 따라 탭이 바뀐다. 전체 규칙은 [layout-data.md](layout-data.md).
- **개요**: 장면 목록(자동 탐지), 장면별 첫 문장·글자 수, 클릭 이동
- **메모**: 이 회차의 본문 메모·회차 메모 스레드, 답글, 완료
- **등장 설정**: 현재 회차에 등장하는 설정집 카드 목록, 선택된 카드 요약
- **기록**: S10
- **찾기**: S9

### 하단 상태줄
- 공백 포함 / 공백 제외 글자 수 (선택 영역이 있으면 선택 영역 기준)
- 연재 플랫폼을 고른 웹소설: "노벨피아 기준 N자" (마우스를 올리면 세는 법). 회차 목표 진행도 이 수로
- 원고지 매수
- 회차 목표 진행률
- 오늘 쓴 양
- 마지막 기록 시각

### 상태
- 빈 회차: "여기에 쓰기 시작하세요" 자리표시 문구
- 저장 실패: 상단 바 빨간 표시 + 배너(디스크 가득 참, 권한 없음 등 원인), 작성은 계속 가능
- 다른 기기에서 바뀜 (동기화 폴더):
  - 이 기기에서 고치던 중이 아니면 바로 불러오고 "다른 기기에서 고친 내용을 불러옴" 알림 (이전 글은 기록에).
  - 고치던 중이면 저장을 멈추고 배너: "다른 기기에서 이 회차가 고쳐졌음" → 둘 다 보기 / 다른 기기 것 불러오기 / 이 기기 것으로 저장. 상단 저장 표시는 "다른 기기에서 바뀜". 고르지 않은 쪽 글은 기록에 남음.
  - 동기화 프로그램이 남긴 사본: 트리에 "사본" 표시, 본문 위 배너 "다른 기기에서 저장한 사본이 있음" → 둘 다 보기 / 정리하기(사본으로 바꾸기, 둘 다 두기, 사본 버리기). 상태줄 "다른 기기 사본 N개"로 전체 목록.
  - 둘 다 보기: 두 글을 나란히, 달라진 곳 N군데, 바뀐 글자 표시, 같은 문단은 접기.
- 읽을 수 없는 회차 (파일은 있는데 비었거나 다른 글자 방식이거나 회차 정보가 깨짐): 트리의 원래 자리에 흐리게, 짐작한 제목과 "열 수 없음" 표시(번호는 붙이지 않음). 누르면 "고쳐 열기" 창(`workspace/MendDialog.tsx`): 까닭, 어떤 글자 방식으로 읽었는지, 제목·글자 수와 본문 앞부분 미리 보기, "원래 파일은 지우지 않고 같은 폴더에 ‘<id>.md.broken-시각’ 이름으로 남겨 둡니다" → [닫기] [고쳐 열기]. 다른 프로그램이 파일을 잡고 있으면 고치기 대신 "잠시 뒤 작품을 다시 열어 보세요". 찾기와 등장 위치는 "열 수 없는 문서 2개는 빼고 찾았습니다", 증명서 창은 만들기 전에 "열 수 없는 회차 N개(…)는 ‘빠진 회차’로 적힙니다", 내보내기는 실패한 회차 이름을 알린다.

## S5. 이어보기 모드

- 트리에서 여러 회차 선택 후 실행, 또는 부 전체 선택
- 회차 사이에 얇은 구분선 + 회차 번호·제목 표시
- 편집 가능, 저장은 회차별
- 상태줄은 전체 합계와 현재 커서가 있는 회차 기준을 함께 표시
- 종료 버튼 (상단 바)

## S6. 집중 모드

- 트리·패널·상단 바 숨김, 본문 한 단
- 현재 문단 강조(다른 문단 흐리게), 켜고 끄기 가능
- 타자기 스크롤(커서 줄을 화면 가운데에 고정), 켜고 끄기 가능
- 하단: 회차 목표 진행, 오늘 쓴 양
- Esc로 종료, 마우스를 위로 올리면 상단 바 잠깐 표시

## S7. 분할 창

- 가운데를 좌우 또는 위아래 두 창으로 분할 (최대 2개)
- 창마다 탭 줄, 창마다 읽기 전용 잠금 토글
- 같은 회차를 양쪽에 열 수 있음 (실시간 동기화)
- 자료(PDF·이미지)를 한쪽에 띄우고 원고 쓰기
- 오른쪽 맥락 패널은 포커스가 있는 창을 따름
- 모바일: 하단 시트로 열기

## S8. 설정집

### 목록
- 분류 탭: 인물 / 장소 / 용어 + 사용자 분류 (예: 세력, 아이템, 스킬). 메모는 설정집이 아니라 따로 있는 메모 기능(layout-data.md)
- 분류 관리: 이름, 아이콘, 기본 필드 목록 편집
- 카드: 이름, 요약 한 줄, 등장 회차 수
- 정렬: 이름순, 최근 수정순, 등장 많은 순
- 새 카드 버튼, 검색

### 카드 편집
| 항목 | 설명 |
|---|---|
| 이름 | 필수 |
| 별칭 | 본문 자동 강조에 사용 (예: 서하, 윤 사장) |
| 분류 | 인물 / 장소 / 용어 / 사용자 분류 |
| 기본 필드 | 인물: 나이, 직업, 말투, 외모, 관계 / 장소: 위치, 특징 / 용어: 정의 / 사용자 분류: 분류에서 정의한 필드 |
| 사용자 필드 | 이름-값 쌍 추가 |
| 본문 메모 | 자유 서술 |
| 등장 회차 | 자동 계산 (이름·별칭 기준), 클릭 시 해당 위치로 이동 |

- 본문 강조 켜고 끄기 (카드별)

## S9. 작품 전체 찾기/바꾸기

- 찾기 입력, 바꾸기 입력
- 범위: 현재 회차 / 현재 부 / 작품 전체 / 설정집 포함
- 옵션: 단어 단위, 정규식
- 결과: 회차별로 묶어서 표시(회차명, 일치 수, 앞뒤 문맥), 클릭 시 이동
- 바꾸기: 하나씩 / 모두 바꾸기 (모두 바꾸기 전 자동 기록, 바뀔 개수 확인)

## S10. 기록 (스냅샷)

화면 이름은 "기록". 버튼은 "지금 원고 보관", "지금과 비교", "이 때로 되돌리기".

- 목록: 시각, 종류(자동 / 직접 보관 / 바꾸기 전 / 되돌리기 전 / 퇴고 전), 이름(직접 보관), 글자 수 변화(+/-)
- 범위: 현재 회차 / 작품 전체
- 선택 시 미리보기
- 지금과 비교: 지금 원고와 나란히, 추가·삭제 부분 색 표시
- 이 때로 되돌리기: 되돌리기 전 지금 원고를 자동으로 기록한 뒤 되돌림
- 지금 원고 보관 (이름 입력)

## S11. 내보내기

| 항목 | 입력 |
|---|---|
| 범위 | 회차 체크 목록 (부 단위 전체 선택), 현재 회차, 작품 전체 |
| 형식 | txt / docx / HWPX / 클립보드 |
| 붙여넣기 서식 (클립보드) | 플랫폼에 맞추기(작품의 연재 플랫폼이 기본), 문단 사이에 빈 줄 넣기, 붙여 넣는 방식(글자만 / 문단 나눔도 함께), 첫 회차 앞부분 미리보기 ([platforms.md](platforms.md)) |
| 원고 서식 프리셋 | 목록 + "이번만 수정" |
| 나누기 | 파일 하나로 / 회차별 파일로 |
| 포함 | 회차 제목, 부 제목, 장면 구분자 표시 방식 |
| 파일 이름 | 규칙 (예: `{작품명}_{회차번호}`) |
| 저장 위치 | 폴더 선택 |

- 미리보기: 첫 쪽 모양(docx/HWPX) 또는 첫 부분 텍스트(txt/클립보드)
- 완료 후: "폴더 열기" 버튼

## S12. 프로젝트 설정

- **기본 정보**: 제목, 유형, 필명, 저장 위치(읽기 전용 + 폴더 열기)
- **목표**: 연재 플랫폼(웹소설: 고르면 최소 분량을 목표로 넣고 세는 법 한두 문장, "세는 법 바꾸기"에서 공백·문장부호·이모지·< > & 켜고 끄기, 추정인 규칙은 그렇다고 알림), 회차 목표 분량, 공백 포함/제외 기준(플랫폼이 없을 때), 하루 목표(선택)
- **장면 구분자**: 사용할 기호, 화면 표시 방식
- **원고 서식**: mvp-scope.md "원고 서식" 표의 항목 전체 + 프리셋 저장/불러오기, 미리보기

## S13. 앱 환경설정

- **작성 화면**: 글꼴, 글자 크기, 줄 간격, 자간, 문단 간격, 첫 줄 들여쓰기, 본문 폭, 테마(라이트/다크/시스템), 화면 색(기본 색 + 직접 고르기), 강조 색, 미리보기 문단
- **편집**: 현재 문단 강조, 타자기 스크롤, 따옴표 자동 변환(" → “ ”, ' → ‘ ’), 말줄임표 자동 변환(... → …). 자동 변환은 기본 꺼짐
- **저장**: 자동 저장 간격, 자동 기록 간격, 기록 보관 기간, 휴지통 보관 기간
- **단축키**: 목록 + 변경
- **정보**: 버전, 오픈소스 라이선스, 업데이트 확인

## S14. 개요 표

- 부 하나(또는 선택한 회차들)를 표로 보기
- 열: 번호, 제목, 시놉시스, 상태 라벨, 글자 수 / 목표(연재 플랫폼이 있으면 "분량 (○○ 기준)"), 열린 메모 수, 마지막 수정
- 제목·시놉시스·상태는 셀에서 바로 편집
- 행 드래그로 순서 변경, 행 더블클릭으로 회차 열기
- 열 보이기/숨기기, 상태 라벨로 필터
- 하단 합계: 회차 수, 총 글자 수, 상태별 개수

## S15. 기획 문서

- 회차 에디터와 같은 에디터
- 분량 목표·상태 라벨 없음, 원고 글자 수 합계에 포함 안 됨

## S17. 마감

프로젝트 유형에 따라 내용이 바뀐다. 디자인 캔버스의 "구조 B · 마감" 보드 두 장.

### 웹소설: 연재

- 비축 현황 (비축 N화 / 목표), 다음 연재 일시, 원고가 모자라는 날 경고
- 연재 일정 달력 (요일·시각 규칙, 예약됨 / 예약 전 / 초안 / 원고 없음)
- 회차 끝 문장 목록 (끊기는 곳 확인), 끊기 후보
- 휴대폰 독자 미리보기 (화면 폭, 글꼴)

### 출판: 교정

- 교정 단계 (탈고 → 1교 → 2교 → 3교 → 인쇄 넘김), 회신 마감일과 남은 날
- 받은 교정본 파일과 비교 기준(편집자에게 보낸 원고, 보낸 날)
- 진행: 바뀐 곳 중 확인한 곳, 남은 곳, 답하지 않은 편집자 메모
- 본문: 지운 글자는 취소선, 넣은 글자는 밑줄. 여백에 편집자 메모 카드
- 바뀐 곳마다 받아들이기 / 되돌리기 / 답글, 남은 곳 모두 받아들이기
- 다음 교정 원고 보내기 (HWPX/docx)
- 원고지 매수, 판형 기준 예상 쪽수

보내기·받기·검토는 S18로 먼저 들어갔다. 마감 모드가 생기면 그 안에서 S18을 연다.

## S18. 교정본 주고받기

엔진·데이터·읽기 규칙은 [corrections.md](corrections.md).

### 편집자에게 보내기 (내보내기 창의 다른 모양)

- 여는 곳: 오른쪽 ⋯ 메뉴 "편집자에게 보내기…", 부 메뉴 "이 부를 편집자에게 보내기…"(그 부의 회차가 골라진 채), 보낸 원고 목록의 "편집자에게 보내기…". 보통 내보내기 창에서도 한글·Word를 고르면 "편집자에게 보내는 원고로 남기기"를 켤 수 있다.
- 맨 위 한 문단: 보낸 원고를 남겨 두었다가 교정본을 받으면 비교한다는 설명.
- 범위: 지금 회차 / 작품 전체 / 골라서(회차 목록에 체크). 형식: 한글(HWPX) / Word(docx)만. 원고 서식, 파일 하나로 / 회차마다 파일 하나, 제목 줄, 장면 나눔 표시는 내보내기와 같다.
- 버튼: 보낸 원고 보기 · 취소 · 보낼 파일 만들기. 만든 뒤 알림 "편집자에게 보낼 파일을 만들었습니다. 교정본을 받으면 ‘교정본 주고받기’에서 가져오세요." (+ 폴더 열기)

### 교정본 주고받기 (보낸 원고 목록)

- 여는 곳: 오른쪽 ⋯ 메뉴 "교정본 주고받기".
- 줄마다: "10월 3일 보냄", 한글 파일 / Word 파일, 회차("1화 문 닫는 시간 외 2개"), 파일 이름, 상태 한 문장(받지 않음 / 정하지 않은 곳 N군데 / 모두 살펴봄).
- 버튼: 교정본 가져오기…(받은 것이 없을 때 강조) 또는 다른 교정본 가져오기…, 검토 이어 하기 / 검토 보기. 아래: 편집자에게 보내기…
- 빈 상태: 보내기로 무엇이 남는지 설명하는 한 문단. 옛 한글(.hwp)은 hwpx로 저장해 달라는 안내.
- 교정본 가져오기: 파일 고르기 창(hwpx·docx) → "교정본을 읽는 중" → 검토 탭이 열린다. 보낸 원고를 찾지 못하면 그 이유를 알림으로.

### 교정본 검토 (가운데 탭)

- 탭 이름은 받은 파일 이름. 맨 위: 파일 이름, "10월 3일에 보낸 원고(1화 … 외 2개)와 비교했습니다. 10월 5일에 가져옴.", 진행 문장("바뀐 곳 9군데가 남았습니다. 받아들이거나 되돌릴 곳을 고른 뒤 ‘반영하기’를 누르세요." / "고른 것 3개는 ‘반영하기’를 눌러야 원고에 들어갑니다…"), 다른 교정본 가져오기…, 반영하기 · N개.
- 회차 칩(여러 회차를 보냈을 때): 제목과 남은 곳 수.
- 본문(왼쪽): 지금 원고. 지운 글은 강조색 취소선, 넣은 글은 파란 밑줄, 지운 문단 나눔은 ¶, 넣거나 뺀 빈칸은 밑줄 칸으로 보인다. 받아들이기로 고르면 지운 글이 흐려지고, 되돌리기로 고르면 넣은 글이 흐려진다. 살펴볼 곳은 연한 노랑 바탕과 ●, 편집자 메모가 붙은 글은 메모 색과 메모 표시. 겹침·지워진 회차·이 파일에 없는 회차는 본문 위 안내 문장.
- 목록(오른쪽): 종류별로(띄어쓰기 / 문장부호 / 문장 고침, 군데 수, 모두 받아들이기 ↔ 모두 받아들임 · 취소), 남은 곳 모두 받아들이기. 바뀐 곳: 종류, 앞뒤 글과 바뀐 글, 변경 내용 추적이면 작성자·때, 받아들이기 / 되돌리기(겹침이면 받아들이기 막힘 + 한 문장 설명 + 회차 열기). 이미 정한 곳(접힘). 살펴볼 곳(형광펜·밑줄·글자색). 편집자 메모(작성자·때, 붙은 글, 메모로 남기기 / 버리기, 남긴 뒤 메모 보기).
- 본문의 표시를 누르면 목록의 그 줄로, 목록 줄을 누르면 본문의 그 자리로 간다.
- 반영한 뒤: 열린 회차는 그 자리에서 새 글로 바뀐다. 알림 한 문장 + "기록 보기"(그 회차의 기록 탭, "교정 반영 전").
